# 4. 실험 결과 및 분석

## 4.1 실험 조건 및 비교 기준

본 장에서는 법령을 검색해 답변을 생성하는 과정에서 재정렬 모델을 바꾸면, 필요한 근거를 더 잘 선택하고 더 나은 답변을 만드는지 살펴본다. 평가에는 한국어 법률 질의응답 벤치마크인 KoBLEX의 공식 한국어 226문항을 사용하였다. 비교 대상은 ParSeR 절차에서 후보 법령의 관련도를 점수화하는 CE(cross-encoder)와 이를 대체한 Jev이다. CE는 질문과 후보 법령을 함께 입력받아 관련도 점수를 산출하는 모델이며, Jev도 이번 실험에서 같은 후보들의 순서를 정하는 역할을 맡았다.

ParSeR의 처리 절차는 다음과 같다. 여기서 **예상 법령**은 질문에 답하는 데 필요할 것으로 모델이 예상하여 생성한 법령 문구이며, 평가 자료에 주어진 정답 근거와는 구별된다.

1. 질문과 배경을 바탕으로 예상 법령 문구를 생성한다.
2. 예상 법령마다 검색 대상 법령 자료(corpus)에서 단어 일치에 기반한 BM25 검색으로 후보 100개를 찾는다.
3. 원 질문과 각 후보 법령을 CE 또는 Jev로 점수화하고, 예상 법령별 상위 10개를 추린다. 이 상위 후보 목록을 이후 **shortlist**라고 부른다.
4. 공통 대규모 언어 모델(LLM) 선택기가 shortlist마다 하나의 근거를 선택한다.
5. 최종 선택한 근거를 답변 생성 모델에 제공한다.

세 조건은 예상 법령과 BM25 후보를 공유하며, 선택·답변 생성 프롬프트와 평가 기준도 동일하게 유지하였다. 따라서 주 비교는 같은 문항·같은 후보에 대해 재정렬 모델만 바꾼 두 조건의 결과를 짝지어 비교한 것이다. 최종 선택 목록의 길이는 예상 법령 수에 따라 달라진다. 서로 다른 목록에서 같은 근거를 선택할 수 있으므로, 목록 길이와 고유 근거 수는 다를 수 있다. 평가 자료의 추론 단계 구분인 hop 정보는 선택 개수를 정하는 데 사용하지 않았다.

공개 코드에서는 LLM이 현재 후보 목록에서 고른 번호를 항상 첫 번째 후보 목록에 적용하는 참조 인덱스 문제가 확인되었다. 이 문제를 수정한 CE를 **주 기준선인 수정 CE**로 두고, 동일한 수정 절차에서 점수화 모델을 바꾼 **Jev 교체** 조건과 비교하였다. 문제를 보존한 공개 코드 CE는 재현 점검용 참조 조건이다([표 1](#tab-ch4-conditions)). 이렇게 구분하면 인덱스 수정에 따른 변화와 모델 교체에 따른 변화를 따로 확인할 수 있다.

<a id="tab-ch4-conditions"></a>

**표 1. 비교 조건의 구성**

| 조건 | 점수화 모델 | 선택 번호를 적용할 후보 목록 | 비교에서의 역할 |
| --- | --- | --- | --- |

평가 자료에 제시된 정답 근거를 이후 **gold**라고 부른다. 일부 gold는 검색 대상 자료에서 동일한 문자열을 찾을 수 없으며, 이 문제가 영향을 주는 문항은 29개이다. 이 문항들을 제외하지 않고 전체 226문항을 주 분석의 분모로 삼았다. 그 영향은 4.3절에서 별도로 살펴본다. 모든 비교는 기존 시험 결과를 확인한 이후 수행한 탐색적 재현 분석이다.

## 4.2 재정렬 모델 교체에 따른 근거 선택 성능

근거 선택 성능은 최종 선택 근거가 gold와 얼마나 일치하는지로 평가하였다. 각 문항에서 근거의 문자열을 집합으로 만들어 비교하므로, 같은 근거를 중복 선택해도 이 평가에서는 하나로 센다. 주요 지표는 다음과 같다.

- **Recall(재현율)**: 각 문항의 gold 가운데 최종 선택에 포함된 비율이다.
- **F1**: 선택한 근거 중 gold의 비율인 정밀도와 Recall의 조화평균이다. gold의 누락과 gold 외 근거의 선택을 함께 반영한다.
- **EM(완전 일치율)**: 최종 선택 근거 집합이 gold 집합과 정확히 같은 문항의 비율이다.
- **모든 gold 포함률**: gold를 하나도 빠짐없이 선택한 문항의 비율이다. EM과 달리 gold 외 근거가 추가되어도 인정한다. 이후 이 조건을 충족하는 것을 **완전 회수**라고 부른다.

F1과 Recall은 문항별 점수를 구한 뒤 모든 문항에 같은 가중치를 주어 평균하였다. 따라서 평균 F1이나 Recall이 높아지는 것과 완전 회수 문항이 늘어나는 것은 서로 다른 결과이다.

예를 들어 gold가 A·B인 문항에서 A만 선택하면 부분 회수이다. A·B·C를 선택하면 완전 회수에 해당하지만 EM은 충족하지 않는다. A·B만 선택해야 완전 회수와 EM을 모두 충족한다.

Jev의 최종 근거 F1은 61.75점으로 수정 CE의 58.57점보다 3.19점 높았다([표 2](#tab-ch4-main-results)). 차이의 탐색적 95% 신뢰구간은 [+0.75, +5.68]점이었다. Recall도 57.74점에서 60.69점으로 2.95점 증가하였으며, 차이의 신뢰구간은 [+0.39, +5.51]점이었다. 두 지표는 Jev 조건에서 평균적으로 gold를 더 많이 회수했음을 보여준다.

<a id="tab-ch4-main-results"></a>

**표 2. 수정 CE와 Jev의 전체 성능 비교 (n=226)**

| 지표 | 수정 CE | Jev | Δ | 차이의 95% CI |
| --- | --- | --- | --- | --- |
| **근거 선택** |  |  |  |  |
| F1 | 58.57 | 61.75 | +3.19 | [+0.75, +5.68] |
| Recall | 57.74 | 60.69 | +2.95 | [+0.39, +5.51] |
| EM | 27.88 | 29.65 | +1.77 | [-1.77, +5.19] |
| 모든 gold 포함률 | 34.07 | 34.96 | +0.88 | [-2.90, +4.53] |
| **답변 품질** |  |  |  |  |
| Token F1 | 46.20 | 47.31 | +1.12 | [+0.02, +2.27] |
| LF-Eval | 67.57 | 70.15 | +2.58 | [+0.37, +4.79] |

주: 값은 0–1 원점수의 100배이며, EM과 모든 gold 포함률은 백분율이다. Δ는 Jev−수정 CE로, 양수이면 Jev가 높다. EM과 모든 gold 포함률의 차이는 퍼센트포인트(%p), 나머지 지표의 차이는 점 단위이다. 차이와 신뢰구간(CI)은 반올림 전 값으로 계산하였다. 답변 품질 지표는 4.4절에서 설명한다.

신뢰구간은 같은 출처나 gold를 공유하는 문항 간의 의존성을 고려하여 산출하였다. 문항들을 151개 그룹으로 묶고, 각 문항의 두 조건 결과를 짝지은 채 그룹 단위로 복원추출하는 대응 bootstrap을 10,000회 수행하였다. 표에는 그 차이 분포의 양끝 2.5%를 제외한 탐색적 95% percentile 구간을 제시하였다. 여러 지표를 동시에 비교하는 데 따른 다중 비교 보정은 적용하지 않았다.

정답 근거를 모두 확보하는 성능의 개선은 불확실했다. EM의 증가폭은 1.77%p였고 신뢰구간은 0을 포함하였다. 완전 회수 문항은 수정 CE 77개에서 Jev 79개로 늘었으나, 비율 차이는 0.88%p에 그쳤으며 신뢰구간은 [-2.90, +4.53]%p였다. 이 구간에는 개선과 악화 방향이 모두 포함된다. 평균 F1과 Recall은 높아졌지만, 모든 정답 근거를 갖춘 문항의 비율에서는 뚜렷한 차이를 확인하기 어려웠다.

최종 선택 이전의 후보를 살펴보면, Jev는 더 많은 gold를 shortlist에 남겼다. 한 문항의 예상 법령별 BM25 후보를 모두 합쳤을 때 평균 gold Recall은 77.21%, 모든 gold 포함률은 61.06%(138/226)였다. 이는 재정렬 전 두 조건이 공유한 후보의 회수 수준이다. 재정렬 후 예상 법령별 상위 10개를 합친 shortlist의 평균 gold Recall은 수정 CE 69.47%, Jev 74.63%였다.

다만 shortlist 전체에 gold가 모두 있더라도, 하나의 목록에 여러 gold가 몰려 있으면 목록당 하나만 고르는 절차에서 전부 선택하지 못할 수 있다. 이 제약까지 고려했을 때 완전 회수가 가능한 문항은 수정 CE 104개, Jev 120개였다. 이는 해당 후보 목록과 선택 규칙에서 가능한 문항 수의 상한이다. 실제 완전 회수 문항은 각각 77개와 79개로 더 적었다. 따라서 shortlist의 회수 개선이 최종 선택의 완결성으로 그대로 이어지지는 않았다. 본 절의 최종 성능은 재정렬과 후속 LLM 선택을 거친 전체 절차의 결과로 해석해야 한다.

공개 코드 CE의 F1은 48.72점으로 수정 CE보다 9.85점 낮았다. 이 차이는 목록 참조 인덱스 수정에 따른 것으로, Jev 교체의 3.19점과 별개의 결과다. 문제를 확인한 범위는 공개 코드 스냅샷이며, 원 논문의 실제 실행에도 같은 문제가 있었는지는 확인되지 않았다.

## 4.3 질문 조건에 따른 성능 차이

전체 평균의 차이가 질문 유형에서도 동일하게 나타나는지 확인하기 위해 공식 hop 구분별로 결과를 살펴보았다. hop은 여러 근거를 연결해 답에 이르는 추론 단계의 구분을 뜻한다. 여기서는 평가 자료가 부여한 1·2·3-hop 표기를 사용하며, 이 숫자가 각 문항의 실제 gold 개수와 항상 같지는 않다.

근거 F1의 개선은 2·3-hop에서 나타났으며, 1-hop에서는 수정 CE가 소폭 높았다([그림 1](#fig-ch4-hop-f1)). 1-hop 57문항의 F1은 수정 CE 78.07점, Jev 76.90점으로 Jev가 1.17점 낮았다. 2-hop 127문항에서는 53.33점에서 57.24점으로 3.91점, 3-hop 42문항에서는 47.91점에서 54.83점으로 6.92점 높았다. 이 차이는 관측된 평균의 패턴이다. hop 집단 간에 모델 교체 효과가 실제로 다른지 확인하는 상호작용 검정은 수행하지 않았다.

<a id="fig-ch4-hop-f1"></a>

![공식 hop별 최종 근거 F1](figures/hop_f1.png)

**그림 1. 공식 hop별 최종 근거 F1. 표본 수는 각각 57, 127, 42문항이다. 각 점은 해당 집단의 문항 평균이며, 집단별 신뢰구간은 산출하지 않았다.**

3-hop의 평균 F1이 높아져도 완전 회수는 두 조건 모두 1문항(1/42, 2.38%)에 머물렀다. 평균 F1의 증가가 모든 정답 근거의 확보로 이어지지는 않았다.

gold를 검색 대상 자료에서 찾을 수 있는지에 따라서도 성능 차이가 컸다. 전체 문항에서 중복을 제거한 gold는 386개이며, 이 중 27개는 corpus에서 동일한 문자열을 찾을 수 없어 29문항에 영향을 주었다. 이를 **매핑 불일치**라고 한다. 해당 gold는 현재 검색 자료와 문자열 일치 기준으로는 회수할 수 없다.

모든 gold가 매핑된 197문항의 F1은 수정 CE 64.12점, Jev 67.21점이었으며, 매핑 불일치의 영향을 받은 29문항에서는 각각 20.80점과 24.71점이었다. 두 집단 모두 Jev의 관측 평균이 높았다. 다만 매핑 불일치 집단의 낮은 점수에는 검색·선택 성능뿐 아니라 자료와 평가 기준의 제약도 반영된다. 또한 문자열이 다른 대체 근거의 법률적 타당성은 이 점수로 평가할 수 없다. 이 분석은 전체 226문항의 주 결과를 보완하는 진단이다.

문항별 F1은 대부분 같았고, 차이가 난 문항에서는 개선과 악화가 함께 관찰되었다. 반올림 전 차이에 10⁻¹²의 동률 허용오차를 적용했을 때, Jev가 높은 문항은 32개, 같은 문항은 177개, 수정 CE가 높은 문항은 17개였다. 따라서 전체 평균의 개선은 모든 문항에서 고르게 발생한 변화가 아니다. 이 개수에는 같은 출처나 gold를 공유하는 문항들이 포함되므로, 각 문항을 서로 독립적인 시행으로 간주한 성공률로 해석할 수는 없다.

## 4.4 자동 답변 품질 및 자원 사용 특성

선택 근거의 변화가 최종 답변에도 나타나는지 살펴보기 위해 두 자동 평가 지표를 사용하였다. **Token F1**은 정규화한 생성 답변과 정답 답변을 공백 단위로 나눈 뒤, 겹치는 토큰을 정밀도와 재현율로 평가한 점수이다. **LF-Eval**은 LLM 평가기가 공식 정답 답변과 gold를 기준으로 생성 답변의 법률적 정확성, 누락, 모순 등을 평가한 점수이다. 전자는 표현의 중복을, 후자는 정답과 정답 근거를 기준으로 한 자동 판단을 반영한다.

Jev 조건에서는 두 자동 평가 점수가 모두 높았다([표 2](#tab-ch4-main-results) 하단). LF-Eval은 수정 CE 67.57점에서 Jev 70.15점으로 2.58점 증가하였으며, 차이의 탐색적 95% 신뢰구간은 [+0.37, +4.79]점이었다. Token F1은 46.20점에서 47.31점으로 1.12점 증가하였고, 차이의 탐색적 95% 신뢰구간은 [+0.02, +2.27]점이었다. 두 평가 모두 공식 코드와 같이 생성 답변의 앞 800자까지를 평가 대상으로 삼았다.

Token F1의 증가를 통계적으로 뚜렷한 개선으로 단정하기는 어렵다. 차이의 percentile 신뢰구간은 0보다 높았지만, 차이 분포를 중심화하는 별도의 centered-bootstrap 양측 검정에서 p값은 약 0.0525였다. 이 구간과 검정은 같은 방식으로 구성한 구간·검정 쌍이 아니므로 결과가 일치하지 않을 수 있다. 이 점과 탐색적 분석이라는 성격을 고려하여, 자동 지표 전체를 통계적으로 유의한 개선으로 묶어 해석하지 않았다.

LF-Eval의 기준 근거는 시스템이 실제로 선택한 근거가 아니라 공식 gold이다. 따라서 이 점수가 높아졌다는 사실만으로 실제 제공 근거가 답변의 각 주장을 지지한다고 볼 수는 없다. 이를 확인하려면 별도의 사람 평가가 필요하다. 기존 60문항·세 조건의 총 180답변에 대해 조건명을 숨긴 블라인드 평가 양식은 준비되었으나, 실제 판단은 아직 없다. 사람이 판정한 답변 정확도, 제공 근거의 주장 지지율, 평가자 간 일치도는 미측정 상태이며, 본 절의 품질 결과는 자동 평가에 한정된다.

자동 점수의 증가와 함께 답변 생성에 필요한 평균 문맥·입력량도 소폭 늘었다. 여기서 **문맥**은 답변 생성 모델에 제공한 선택 근거이며, 사용량을 나타내는 토큰은 모델의 토크나이저가 나눈 단위이다. 앞서 Token F1에서 사용한 공백 단위 토큰과는 정의가 다르다.

**표 3. 답변 생성 단계의 토큰 사용량 (n=226)**

| 답변 생성 단계의 사용량 | 수정 CE | Jev |
| --- | --- | --- |
| 문맥 토큰 평균 | 203.67개 | 215.60개 |
| 문맥 토큰 중앙값 | 164개 | 170.5개 |
| 문맥 토큰 사분위 범위(IQR) | 133.75개 | 142.50개 |
| 전체 API 입력 토큰 평균 | 2302.67개 | 2314.58개 |
| API 출력 토큰 평균 | 72.16개 | 73.98개 |

주: IQR은 상위 25%와 하위 25%의 경계값 차이로, 가운데 절반의 값이 퍼진 폭을 나타낸다. 전체 API 입력에는 선택 근거뿐 아니라 질문·지시문·예시도 포함된다.

각 문항에서 Jev−수정 CE로 구한 문맥 토큰 차이는 평균 +11.93개, 중앙값 0개, IQR 2.50개였다. 평균 입력량의 절감은 관찰되지 않았다. 또한 문맥 길이와 품질이 함께 증가했다는 관측만으로 문맥 길이가 품질 차이의 원인이라고 판단할 수는 없다.

두 조건의 선택 목록 길이는 문항별로 같았으며, 전체 문항의 선택 항목을 합하면 각 조건에서 478개였다. 문항마다 중복을 제거한 근거 수를 합하면 수정 CE 407개, Jev 409개였고, 목록 내 중복 출현은 각각 71회와 69회였다. 이는 전체 문항을 통틀어 중복을 제거한 수와는 다르다. 따라서 이번 비교에서 달라진 것은 선택 내용과 중복 양상이며, 선택 개수를 줄이는 필터링(Filtering)은 적용하지 않았다.

문맥 토큰은 실제 제공 목록의 순서와 중복을 유지하고 줄바꿈으로 연결한 문자열에 `o200k_base` 토크나이저를 적용해 산출하였다. 전체 API 입력·출력량은 생성 응답의 사용량 기록을 사용하였다.

위 사용량에는 저장된 생성 응답인 캐시를 재사용한 문항도 포함된다. 해당 문항은 수정 CE 72개, Jev 122개였다. 캐시를 재사용한 경우에도 그 입력과 답변에 해당하는 토큰량을 집계했으므로, 위 수치는 이번 실행에서 새로 청구된 사용량을 뜻하지 않는다. 또한 근거 선택·점수화·평가·재시도와 로컬 CE 운영비까지 모두 반영한 조건별 서비스 비용은 산출하지 않았다. 실행 시간에도 캐시 재사용과 요청 제한에 따른 대기가 포함되어 있어, 실제 서비스에서의 응답 지연을 공정하게 비교하는 자료로 사용할 수 없다.

## 4.5 오류 유형 및 관측 사례

최종 선택까지 이어지지 못한 gold가 어느 단계에서 빠졌는지 확인하였다. 집계 단위는 **문항별 gold 출현**이다. 한 문항 안에서는 같은 gold를 한 번만 세되, 같은 gold가 다른 문항에도 필요하면 각 문항에서 따로 센다. 이 방식의 전체 출현은 443건으로, 전체 문항에서 중복을 제거한 gold 386개와 구별된다. 각 출현을 처음 탈락한 단계 또는 최종 선택에 한 번씩 배정하였다.

**표 4. 문항별 gold 출현의 단계별 탈락 및 최종 선택 건수**

| gold의 최초 탈락 단계 또는 최종 상태 | 수정 CE | Jev |
| --- | --- | --- |
| corpus에서 동일한 문자열을 찾을 수 없음 | 33건 | 33건 |
| corpus에는 있으나 BM25 후보에 없음 | 75건 | 75건 |
| BM25 후보에는 있으나 shortlist에서 탈락 | 42건 | 13건 |
| shortlist에는 있으나 최종 선택되지 않음 | 60건 | 72건 |
| 최종 선택에 포함 | 233건 | 250건 |
| 합계 | 443건 | 443건 |

Jev에서는 shortlist 단계에서 탈락한 gold가 42건에서 13건으로 줄고, 최종 선택에 남은 gold가 233건에서 250건으로 늘었다. 반면 shortlist에 남았으나 최종 선택되지 않은 gold도 60건에서 72건으로 늘었다. 앞 단계에서 더 많은 gold를 보존했지만, 그 일부는 후속 선택에서 활용되지 못한 것이다. corpus와 BM25 후보는 두 조건에서 공유하므로 앞선 두 단계의 탈락 건수는 같았다.

이 집계는 gold와 문자열이 일치하는 근거의 회수·선택 상태를 설명한다. shortlist 내 미선택에는 목록당 하나를 고르는 제약과 중복 선택이 관련될 수 있으므로, 이를 곧바로 LLM의 법률 판단 오류로 볼 수는 없다. 별도로 gold 외 근거가 선택된 문항은 수정 CE 126개, Jev 116개였다. gold와 다르다는 사실만으로 그 근거가 법률적으로 무관하다고 판정할 수는 없다. 위 표는 gold 출현 단위의 중복 없는 집계인 반면, 한 문항에는 여러 관측 유형이 겹칠 수 있다. 따라서 문항별 관측 유형의 빈도를 합해 전체 오류 문항 수로 해석해서는 안 된다.

이러한 변화가 개별 질문에서 어떻게 나타나는지 살펴보기 위해 세 사례를 선정하였다. Jev의 근거 F1이 높아진 집단, 수정 CE의 근거 F1이 높은 집단, 근거 F1과 답변 지표의 변화 방향이 반대인 집단에서 각각 하나를 골랐다. 각 집단에서 근거 F1 차이의 절댓값이 집단 중앙값에 가장 가까운 문항을 택하고, 동률이면 문항 식별자(query_id)의 사전순으로 정하였다. [표 5](#tab-ch4-cases)는 이 규칙으로 고른 관측 사례이며, 전체 문항을 통계적으로 대표하는 표본은 아니다.

<a id="tab-ch4-cases"></a>

**표 5. 선정한 관측 사례의 자동 점수 변화 (수정 CE → Jev)**

| 사례 | 질문 주제 | 선정 유형 | 근거 F1 | LF-Eval |
| --- | --- | --- | --- | --- |
| A | 식품 보고 | Jev 개선 | 50.00 → 100.00 | 65.29 → 99.18 |
| B | 복수 청구 | 수정 CE 우세 | 80.00 → 40.00 | 71.79 → 52.67 |
| C | 사면 효과 | 근거 F1과 Token F1의 방향 불일치 | 40.00 → 0.00 | 31.10 → 30.55 |

주: 점수는 0–100 척도이다. 사례 C의 불일치는 표의 LF-Eval이 아니라 아래 본문에 제시한 답변 Token F1과의 비교를 뜻한다. 사례 식별자는 다음과 같다.

- A: `qa_124_2hop_480_rand`
- B: `qa_324_2hop_515`
- C: `qa_443_3hop_703`

사례 A에서는 정답 근거의 완전 회수와 답변 문구의 변화가 함께 나타났다. 식품 생산실적과 위해식품 회수계획의 보고 상대방을 묻는 2-hop 문항이다. 수정 CE는 식품위생법 제42조제2항과 생산실적 관련 시행규칙을 선택하였다. Jev는 gold인 제42조제2항과 제45조제1항을 모두 선택하여, 수정 CE에서 빠졌던 회수계획 관련 gold를 확보하였다. Jev의 답변에는 회수계획의 보고 상대방으로 시장·군수·구청장이 포함되었으며, 근거 F1과 LF-Eval이 모두 높아졌다.

사례 B에서는 Jev의 shortlist에서 gold가 탈락하고 두 자동 점수가 낮아졌다. 여러 당사자를 상대로 복수 청구를 제기하는 절차에 관한 2-hop 문항이다. 수정 CE는 gold인 민사소송법 제79조제1항과 제253조를 모두 선택하였다. Jev에서는 제79조제1항이 shortlist에서 탈락하고, 최종 근거에 제83조제1항이 포함되었다. 수정 CE 답변은 독립당사자참가, Jev 답변은 공동소송참가에 관한 내용을 담았다. 근거 F1과 LF-Eval은 모두 수정 CE가 높았다. 이 사례에서 확인한 것은 선택 조문과 답변 내용의 차이이며, 각 절차 제도의 실제 적용 가능성은 별도 법률 검토가 필요하다.

사례 C에서는 근거 F1과 답변 Token F1이 반대 방향으로 변했다. 사면과 복수 범죄의 처리에 관한 3-hop 문항으로, gold 3개 중 하나는 corpus에서 동일한 문자열을 찾을 수 없었고 다른 하나는 BM25 후보에 없었다. 또한 생성된 후보 목록이 2개여서, 목록마다 하나를 고르는 현재 절차로는 gold 3개를 모두 선택할 수도 없었다. 수정 CE는 gold 하나를 최종 선택했으나 Jev는 gold와 문자열이 일치하는 근거를 선택하지 않았다. 근거 F1은 40.00점에서 0.00점으로 낮아진 반면 답변 Token F1은 18.60점에서 25.88점으로 높아졌다. 이 사례는 답변의 표현이 정답과 더 많이 겹치는 것과 정답 근거를 더 많이 회수하는 것이 일치하지 않을 수 있음을 보여준다. 사면 유형, 범죄의 경합 관계, gold 외 선택 조문의 타당성은 전문가 검토 사항이다.

세 사례 모두 법률 전문가의 판정이 완료되지 않은 자동 관측 사례이다. 기존 사람 평가 60문항 표본에는 포함되지 않으며, 별도의 정성 검토 대상으로 남겨 두었다. 이 사례들로 블라인드 평가 표본을 교체하거나 사람 평가 결과를 추가하지 않았다. 따라서 사례의 법률적 오류 여부와 실제 제공 근거가 답변의 주장을 지지하는지는 아직 판정되지 않았다.
