# 법률 검토 대기 — 자동 관측과 판정을 구분

상태: **법률 전문가 판정 없음.** [검토 대기 목록](A6/legal-review-queue.csv)의 183문항은 자동 규칙에 따른 확인 대상이다. 오류율·법적 오답 수·근거 지지율로 사용하지 않는다. 공식 gold는 변경하지 않는다. RQ/목차 조율은 [별도 문서](RQ_TOC_COORDINATION.md)에 기록했다.

모든 226문항의 질문·배경·gold ID/원문·정답·수정 CE/Jev의 선택 법령/답변·F1/LF 변화·관측된 탈락 단계는 [casebook](A6/casebook.jsonl)에 있다. `lf_judge_reason_unverified`는 자동 judge의 설명이고 사람의 판단이 아니다. 검토 상태는 전부 `NOT_REVIEWED`다.

이 자료는 조건을 아는 분석자용이다. 독립 사람 평가자에게는 기존 블라인드 양식을 사용하며 이 casebook이나 조건 정보로 사전 노출하지 않는다.

## 검토 시 분리할 판단

1. corpus exact 불일치는 문자열·조문 범위·법령 버전 차이인지 확인한다. 법적으로 사용 가능한 근거가 전혀 없었다고 자동 결론내리지 않는다.
2. BM25/shortlist의 탈락은 기술적 관측이다. shortlist 내 미선택도 pool당 선택 하나 및 중복 제약을 확인하고 법률 판단 오류인지 별도로 검토한다.
3. exact gold 외 조문은 미판정/대체 근거일 수 있다. 자동으로 무관 법령으로 부르지 않는다.
4. 법률적 정확성, 제공 근거에 의한 주장 지지, unsupported legal claim을 각각 확인한다. LF는 gold context 기준의 자동 평가다.
5. 낮은 점수 기준 0.5는 사례 탐색용이다. 모든 gold 선택+낮은 LF는 두 조건 모두 0문항, 모든 gold 선택+낮은 Token F1은 두 조건 각각 29문항이라는 관측만 기록한다. 이를 사람이 확인한 성공/실패 수로 해석하지 않는다.

이번 산출물에는 사람 점수·법률 결론·합의 판정·평가자 자격/참여/일정을 채우지 않았다. 독립 제출본이 도착하면 기존 A7 절차를 적용하며 이 casebook의 자동 관측을 실제 판단으로 변환하지 않는다.
