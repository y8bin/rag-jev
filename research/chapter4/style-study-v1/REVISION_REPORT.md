# 제4장 문체 수정 내역

2026-11-09. [arXiv 원문 10편 검토](READING_NOTES.md)를 바탕으로 4.1–4.5 전체의 문체를 수정했다. 문헌의 문장을 번역해 넣거나 모델 자체를 훈련한 작업은 아니다. 원문에서 관찰한 전개 방식을 현재 실험의 증거 범위에 맞게 적용했다.

## 절별 변경

| 절 | 변경 | 유지한 핵심 경계 |
|---|---|---|
| 4.1 | 주 비교와 참조 조건의 역할을 첫 문단에 모으고 공통 절차를 간결하게 서술 | 수정 CE 대 Jev, 전체 226문항, 후보 100/shortlist 10, 탐색적 재현 |
| 4.2 | F1/Recall 차이를 첫머리에 배치하고 완전 회수의 불확실성, shortlist와 최종 선택의 차이를 연결 | EM/모든 gold 포함률 CI의 0 포함, scorer 단독 효과와의 구분, 인덱스 수정의 별도 효과 |
| 4.3 | hop별 이질성을 결과로 먼저 진술하고 매핑 197/29 진단을 이 절로 이동 | 1-hop 감소, 3-hop 완전 회수 1/42, 상호작용 미검정, 대응 승/동/패의 의존성 |
| 4.4 | 자동 답변 점수 → 지표의 범위 → 입출력량 → 캐시·측정 범위 순으로 정리 | Token F1 p≈0.0525와 구간의 방법 차이, gold context 평가, 실제 사람 판단 부재, 입력량 증가, 지연·전체 비용 미측정 |
| 4.5 | 단계별 관측을 먼저 제시하고 A/B/C를 각기 개선·악화·지표 불일치로 시작 | 443건 분모, 자동 관측과 법률 판단의 구분, 사례 선정 규칙, 표본 밖 사례, 법률 검토 대기 |

표 3개와 그림 환경은 그대로 유지했다. 수치의 표시값·차이·신뢰구간을 바꾸지 않았다. 반복된 ‘해석하지 않는다/구분한다/판단하지 않는다’는 관련 결과와 연결되는 문장으로 정리했으며, 필요한 한계 자체는 삭제하지 않았다. 관련 연구의 점수나 사람 평가 결과를 현재 실험의 결과로 추가하지 않았다.

## 전후 예시

**주 결과의 도입**

- 수정 전: “표는 전체 226문항의 최종 근거 선택 성능과 답변 품질을 제시한다.”
- 수정 후: “Jev의 최종 근거 F1은 61.75점으로 수정 CE의 58.57점보다 3.19점 높았다.” 이후 차이의 탐색적 구간을 바로 제시한다.
- 이유: 표의 존재를 알리는 문장보다 비교 결과를 먼저 읽을 수 있게 했다. RAG §4, RankGPT §6, Lost in the Middle §2.3의 결과 전개를 참고했다.

**하위집단의 도입**

- 수정 전: “전체 평균에서 관찰된 차이가 질문 조건에 따라 어떻게 달라지는지 공식 hop별로 살펴보았다.”
- 수정 후: “근거 F1의 개선은 2ㆍ3-hop에서 나타났으며, 1-hop에서는 수정 CE가 소폭 높았다.”
- 이유: 분석 목적의 반복 대신 관찰된 패턴과 예외를 동시에 제시했다. DPR §5.1과 RankGPT §6.2를 참고했다. 층 간 효과 차이를 검정했다는 뜻은 추가하지 않았다.

**사례의 도입**

- 수정 전: “사례 C는 사면과 복수 범죄의 처리에 관한 3-hop 문항이다.”
- 수정 후: “사례 C에서는 근거 F1과 답변 Token F1이 반대 방향으로 변했다.”
- 이유: 질문 주제에 앞서 이 사례를 제시하는 분석적 이유를 밝혔다. ALCE의 correctness/citation 구분과 RAGChecker의 단계별 진단 전개를 참고했다. 사면 유형과 조문의 법률적 타당성은 미판정으로 유지했다.

## 보존 및 검증

- 수정 전 파일: [백업 원장](before-manifest.json), [백업 폴더](before-revision/).
- 원문 PDF 10편의 제목·버전·출처·SHA-256: [수집 원장](papers-manifest.json).
- 현재 점수의 원자료: 기존 `analysis.json`, `chapter4-prep-v1/A1~A6`, `manuscript-facts.json`. 원문 수집과 문체 수정을 위한 출력은 `research/chapter4/style-study-v1/`에 분리했다.
- [검증 코드](validate_revision.py)는 원 실험 파일 43,076개와 고정 prep 산출물 67개의 해시를 읽기 전용으로 대조하고, 표·그림 환경, 기존 수치 토큰, 사실 원장, LaTeX 참조와 로그를 점검한다. 수치 토큰 검사는 어휘 수준의 보조 검사이며, 문장의 조건·지표 연결은 원자료와 대조해 검토했다.
- XeLaTeX 2회 컴파일 후 3쪽 전체를 렌더링해 확인했다. 최종 상태와 산출물 해시는 [검증 결과](validation.json)에 기록한다.
- 새 유료 실험·추가 통계 검정·새 사람 판단은 수행하지 않았다.

## 별도로 유지한 조율·검토 사항

**RQ/목차·방법 정합성:** 다른 장의 최종 RQ, BM25와 Vector 표현, 미실행 Filtering의 범위, 최종 학회 양식은 기존 [조율 기록](../../../results/koblex-reproduction-v1/chapter4-prep-v1/RQ_TOC_COORDINATION.md)의 대기 사항이다. 이번에는 제4장 문체와 문단 배치만 조정했다.

**법률 검토:** A/B/C 및 gold 외 근거의 적용 가능성·주장 지지·법률적 정오는 기존 [법률 검토 목록](../../../results/koblex-reproduction-v1/chapter4-prep-v1/LEGAL_REVIEW.md)에서 미판정 상태를 유지한다. 이 기록은 RQ 조율과 별개의 전문가 검토 항목이며, 블라인드 사람 평가 표본이나 판단을 변경하지 않았다.
