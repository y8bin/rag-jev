# 제4장 보충 자료

이 자료는 [제4장 본문](chapter4.md)의 평가·집계 방식과 사례 선정 상세를 제공한다. 기존 원자료와 평가 절차를 설명하며, 새로운 실험이나 통계 검정을 추가하지 않는다.

## S1. 평가 절차와 지표 정의

예상 법령은 질문과 배경을 바탕으로 모델이 생성한 검색용 법령 문구이며, 평가 자료가 제공한 정답 근거(gold)와 구별된다. 각 예상 법령을 이용해 corpus에서 BM25 후보 100개를 검색하고, 원 질문과 후보 법령을 CE 또는 Jev로 점수화하여 상위 10개 shortlist를 구성하였다. LLM은 목록마다 하나를 선택하고, 선택 근거를 답변 생성 모델에 제공하였다. 서로 다른 목록에서 같은 근거를 선택할 수 있으므로 선택 항목 수와 고유 근거 수는 다를 수 있다.

근거 평가는 문항별로 최종 선택 근거와 gold의 문자열 집합을 비교한다. 중복 문자열은 한 번만 센다. 정밀도는 선택 근거 중 gold의 비율, Recall은 gold 중 선택된 비율이며 F1은 두 값의 조화평균이다. EM은 두 집합의 완전 일치 여부이고, 모든 gold 포함 여부는 gold가 선택 집합에 모두 포함되는지를 나타낸다. F1·Recall은 문항별 점수의 비가중 평균, EM·모든 gold 포함률은 해당 조건을 충족한 문항의 비율이다.

예를 들어 gold가 A·B인 문항에서 A만 선택하면 부분 회수이다. A·B·C를 선택하면 완전 회수이지만 EM은 충족하지 않는다. A·B만 선택해야 완전 회수와 EM을 모두 충족한다.

Token F1은 정규화한 생성 답변과 정답 답변을 공백 단위로 나누어 토큰 중복을 측정한다. 사용량 토크나이저의 토큰과는 다른 단위이다. LF-Eval은 LLM 평가기가 공식 정답 답변과 gold를 기준으로 답변의 법률적 정확성, 누락, 모순 등을 평가한다. 실제 시스템이 제공한 근거를 기준으로 한 주장 지지 평가와는 구별된다. 두 자동 평가 모두 공식 코드의 처리 규칙에 따라 생성 답변을 전처리하고 앞 800자까지 사용하였다.

신뢰구간은 같은 출처나 gold를 공유하는 문항을 묶은 151개 의존 그룹에 대해 산출하였다. 각 문항의 두 조건 결과를 짝지은 채 그룹 단위로 복원추출하는 대응 bootstrap을 10,000회 수행하고, 차이 분포의 양끝 2.5%를 제외한 percentile 구간을 사용하였다. 문항별 점수는 동일 가중치로 집계하며, 다중 비교는 보정하지 않았다. Token F1에 보고한 centered-bootstrap 양측 p값은 이 percentile 구간과 같은 방식으로 구성한 구간·검정 쌍이 아니다.

## S2. 공개 코드의 후보 목록 참조 문제

공개 코드는 여러 후보 목록에 대한 LLM 선택 결과를 처리할 때 현재 목록 대신 항상 첫 번째 목록의 같은 번호를 참조한다. CE와 Jev 조건은 현재 목록에서 선택된 번호를 읽도록 수정하였다. 공개 코드 CE는 원래 동작을 보존한 참조이며, CE는 후보 목록 참조 방식을 수정한 주 기준선이다. 따라서 공개 코드 CE와 CE의 차이는 이 문제의 수정에 따른 변화이고, CE와 Jev의 차이가 모델 교체의 주 비교이다.

확인 대상은 공개 코드 스냅샷이며, 원 논문의 실제 실행에도 같은 문제가 있었다고 판정한 것은 아니다.

## S3. 자원 사용량과 캐시의 집계

문맥 토큰은 실제 선택 목록의 순서와 중복을 유지하고 줄바꿈으로 연결한 문자열에 `o200k_base` 토크나이저를 적용해 산출하였다. 전체 API 입력·출력량은 생성 응답의 사용량 기록에서 가져왔다. 전체 입력에는 선택 근거 외에 질문·지시문·예시가 포함된다. IQR은 제3사분위수와 제1사분위수의 차이로, 가운데 절반의 값이 퍼진 폭을 나타낸다.

저장된 생성 응답을 재사용한 문항은 CE 72개, Jev 122개였다. 이 문항도 동일 입력과 답변에 해당하는 토큰량을 포함하여 집계하였다. 본문의 사용량은 조건별 생성 단계 요구량이며 이번 실행의 신규 청구액이 아니다. 근거 선택·점수화·평가·재시도와 로컬 CE 운영비를 포함한 독립 서비스 비용은 산출하지 않았다. 실행 시간에는 캐시와 요청 제한 대기가 포함되어 응답 지연의 공정한 비교에 사용할 수 없다.

## S4. 관측 유형과 사례 선정

단계별 집계에서는 한 문항 안의 고유 gold를 한 번씩 세고, 같은 gold가 다른 문항에도 필요하면 각 문항에서 따로 센다. 이 방식의 출현은 조건별 443건이며, 전체 문항에서 중복을 제거한 고유 gold 386개와 구별된다. 각 출현은 최초 탈락 단계 또는 최종 선택 상태 하나에만 배정하였다. 반면 한 문항에는 여러 관측 유형이 겹칠 수 있으므로, 문항별 관측 유형 빈도의 합이 전체 오류 문항 수를 뜻하지는 않는다.

사례 A는 근거 F1이 Jev에서 개선된 집단, B는 CE가 높은 집단, C는 근거 F1과 답변 Token F1 또는 LF-Eval이 엄격히 반대 방향으로 변한 집단에서 선정하였다. 각 집단의 근거 F1 차이 절댓값 중앙값에 가장 가까운 문항을 택하였으며, 동률이면 query_id의 사전순으로 정하였다. 선정된 C는 근거 F1과 Token F1의 불일치 사례이다.

| 사례 | 문항 식별자 | 관측 유형 |
| --- | --- | --- |
| A | `qa_124_2hop_480_rand` | Jev 개선 |
| B | `qa_324_2hop_515` | CE 우세 |
| C | `qa_443_3hop_703` | 근거 F1 감소·Token F1 증가 |

사람 평가를 위해 기존 60문항·세 조건의 총 180답변에 대한 블라인드 양식이 준비되어 있으나, 실제 판단은 아직 없다. 위 세 사례는 모두 그 60문항 표본 밖의 별도 정성 검토 대상이며, 기존 블라인드 표본을 교체하거나 사람 평가 결과에 추가하지 않았다. 자동 평가기의 설명도 전문가의 법률 판정으로 사용하지 않았다.

기존 수치와 사례별 평가값의 출처는 [수치 원장](manuscript-facts.json)에 연결되어 있다. 이 보충 자료의 재배치는 새로운 사람 판단이나 법률적 타당성 판정을 의미하지 않는다.

문맥 토큰의 문항별 Jev−CE 차이는 평균 +11.93개, 중앙값 0개, IQR 2.50개였다. 선택 목록 길이는 문항별로 같았으며 조건별 합계는 478개였다. 문항 내 고유 근거 수의 합은 CE 407개, Jev 409개였고 중복 출현은 각각 71회와 69회였다. 이는 문항마다 중복을 제거한 수를 합한 것으로 전체 문항에서 중복을 제거한 수와 다르다. 선택 수를 줄이는 필터링은 적용하지 않았다.

공통 BM25 후보 합집합의 평균 정답 근거 Recall은 77.21%, 모든 정답 근거 포함률은 61.06%(138/226)였다. 정답 외 근거가 선택된 문항은 CE 126개, Jev 116개였다. 이러한 문자열 집계로 대체 근거의 법률적 타당성을 판정하지 않았다.

### 질문별·추론 단계별 차이

1·2·3-hop의 Jev−CE F1 차이는 각각 −1.17점, +3.91점, +6.92점이었다. 문항별 동률은 반올림 전 차이에 10⁻¹²의 허용오차를 적용하여 판정하였다. 같은 출처나 정답 근거를 공유하는 문항을 포함하므로 개선·동일·악화 개수를 독립 시행의 성공률로 해석하지 않았다. 3-hop의 완전 회수는 두 조건 모두 1/42문항이었다.

사례 C는 정답 근거 3개에 대해 생성된 후보 목록이 2개였으므로, 목록당 하나를 선택하는 현재 절차로는 정답 근거 전부를 선택할 수 없었다. 사례 A의 CE 선택 근거에는 식품위생법 제42조제2항과 생산실적 관련 시행규칙이 포함되었으며, Jev는 제42조제2항과 제45조제1항을 선택하였다. 사례 B에서 두 조건의 공통 정답 선택 근거는 민사소송법 제253조였다.


## S7. 후속 필터링 시뮬레이션

현재 본문의 선택 후 필터링 결과는 `results/koblex-filtering-v1/summary.json`의 `cv_overall`과 대응 bootstrap에 근거한다. 의존 그룹 151개를 5-fold로 나누었으며 seed는 20261109이다. 각 scorer의 학습 fold 점수 분위수로 유지율 1.00~0.05의 20개 격자를 구성했다. 학습 fold의 F1이 원래 값보다 1점 넘게 낮아지지 않는 후보 중 유지 근거 수가 가장 적은 문턱값을 선택하여 검증 fold에 적용했다. 학습 fold의 허용 하락폭은 검증 fold의 성능 보장이나 비열등성 한계 검정이 아니다.

CE의 fold별 문턱값은 0 또는 약 0.0000037~0.0000038, Jev는 0.30~0.40이었다. 검증 fold 통합 유지율은 CE 467/478=97.70%, Jev 426/478=89.12%였다. 이미 본 시험 문항 안의 탐색적 교차검증이므로 미노출 외부 시험을 대신하지 않는다. bootstrap 구간 역시 비열등성 입증으로 사용하지 않는다.

`post_matched_keep_rate.csv`는 전체 분포에서 동일 비율의 선택 근거를 유지한 기술통계다. `pre_matched_keep_rate.csv`는 선택 전 shortlist 후보를 제거했을 때 pool별 gold 출현 유지 수준을 계산한다. 후자의 분모는 질문별 gold 집합이 아니며, LLM을 다시 실행하지 않아 최종 선택·답변 결과를 뜻하지 않는다. 필터링된 근거로 답변을 재생성하거나 사람 판단을 수행하지 않았다.

## S8. 본문 그림과 편집 범위

본문은 완료된 근거 선택·재정렬 품질·자동 답변·자원 집계·필터링·사례 분석을 수록한다. 지연 벤치마크 및 사람 평가 수치는 넣지 않았다. 그림 1~3은 각각 `fig_4_2_evidence_effects_column`, `fig_4_3_shortlist_quality_column`, `fig_4_5_gold_loss_stages_column`이며 기존 원자료를 85mm 단 너비에서 읽을 수 있도록 다시 조판했다. 수치를 새로 추론하거나 신뢰구간을 추가 계산하지 않았다.

조건 흐름도와 자동 답변·토큰 비교 그림을 포함한 절별 전체 figure는 [그림 자료집](figures/section-figures-v1/README.md)에 보존하였다. 본문의 표·수치와 중복되는 그림은 본문에서 생략했다. 지면은 `preview.tex`의 A4, 10pt, 2단, 여백 20mm 기준으로 검증하며 학회 최종 양식의 페이지 수까지 보장하는 것은 아니다.
