# 4. 실험 결과 및 분석

## 4.1 실험 조건 및 비교 기준

본 장은 KoBLEX의 공식 한국어 226문항에서 ParSeR의 CE(cross-encoder)를 Jev로 교체했을 때의 근거 선택 성능과 답변 품질을 비교한다. 주 기준선은 공개 코드의 후보 목록 참조 인덱스 문제를 수정한 CE이며, 같은 파이프라인에서 점수화 모델만 Jev로 교체한 조건과 문항별로 대응 비교하였다. 인덱스 문제를 보존한 공개 코드 CE는 재현 점검을 위한 참조 조건으로 두었다([표 1](#tab-ch4-conditions)).

<a id="tab-ch4-conditions"></a>

**표 1. 비교 조건의 구성**

| 조건 | 점수화 | 선택 인덱스 | 역할 |
| --- | --- | --- | --- |
| 공개 코드 CE | BGE | 문제 보존 | 재현 참조 |
| 수정 CE | BGE | 수정 | 주 기준선 |
| Jev 교체 | Jev | 수정 | 주 비교 |

세 조건은 예상 법령과 BM25 후보를 공유하였다. 예상 법령별 후보 100개를 재정렬하고 상위 10개 중 하나를 공통 LLM 선택기로 선택한 뒤, 선택 근거를 이용해 답변을 생성하였다. 최종 근거 수는 예상 법령 수에 따라 달라지며, 정답 hop 정보는 선택에 사용하지 않았다. 선택ㆍ생성 프롬프트와 평가 기준은 동일하게 유지하였다. CE는 `bge-reranker-v2-m3-ko`, Jev는 `jev-1.14.0`을 사용하였으며, 선택ㆍ답변 생성과 LF-Eval의 평가 모델은 `gpt-4o-2024-08-06`으로 통일하였다.

정답 근거의 일부가 corpus와 정확히 매핑되지 않는 29문항을 포함하여, 전체 226문항을 주 분석의 분모로 삼았다. 모든 비교는 기존 시험 결과를 확인한 이후 수행한 탐색적 재현 분석이다.

## 4.2 재정렬 모델 교체에 따른 근거 선택 성능

Jev의 최종 근거 F1은 61.75점으로 수정 CE의 58.57점보다 3.19점 높았다([표 2](#tab-ch4-main-results)). 차이의 탐색적 95% 신뢰구간은 [+0.75, +5.68]점이었다. Recall도 57.74점에서 60.69점으로 2.95점 증가하였으며, 차이의 신뢰구간은 [+0.39, +5.51]점이었다. 두 지표는 Jev 조건에서 정답 근거의 평균 회수 수준이 높았음을 보여준다.

근거 선택 점수는 공식 정답 근거(gold)와 최종 선택 근거의 문자열 집합을 비교한 문항별 점수의 비가중 평균이다. EM은 두 집합의 완전 일치율이며, 모든 gold 포함률은 추가 근거의 유무와 관계없이 정답 근거를 모두 포함한 문항의 비율이다.

<a id="tab-ch4-main-results"></a>

**표 2. 수정 CE와 Jev의 전체 성능 비교 (n=226)**

| 지표 | 수정 CE | Jev | Δ | 차이의 95% CI |
| --- | --- | --- | --- | --- |
| **근거 선택** |  |  |  |  |
| F1 | 58.57 | 61.75 | +3.19 | [+0.75, +5.68] |
| Recall | 57.74 | 60.69 | +2.95 | [+0.39, +5.51] |
| EM | 27.88 | 29.65 | +1.77 | [-1.77, +5.19] |
| 모든 gold 포함률 | 34.07 | 34.96 | +0.88 | [-2.90, +4.53] |
| **답변 품질** |  |  |  |  |
| Token F1 | 46.20 | 47.31 | +1.12 | [+0.02, +2.27] |
| LF-Eval | 67.57 | 70.15 | +2.58 | [+0.37, +4.79] |

주: 값은 0–1 원점수의 100배이며, EM과 모든 gold 포함률은 백분율이다. Δ는 Jev-수정 CE로, EM과 모든 gold 포함률의 차이는 %p, 나머지 지표의 차이는 점 단위이다. 차이와 CI는 반올림 전 값으로 계산하였다. CI는 151개 의존 그룹의 대응 bootstrap 10,000회로 산출한 탐색적 percentile 구간이며, 다중 비교를 보정하지 않았다.

정답 근거를 모두 확보하는 성능의 개선은 불확실했다. EM의 증가폭은 1.77%p였고 신뢰구간은 0을 포함하였다. 모든 gold를 포함한 문항은 수정 CE 77개에서 Jev 79개로 늘었으나, 비율 차이는 0.88%p에 그쳤으며 신뢰구간은 [-2.90, +4.53]%p였다. 평균 F1과 Recall의 개선에 비해 근거 집합의 완결성에서는 뚜렷한 차이를 확인하기 어려웠다.

Jev의 회수 이점은 LLM 선택기에 제시하는 shortlist에서도 관찰되었다. 공통 BM25 후보 합집합의 문항 평균 gold Recall은 77.21%, 모든 gold 포함률은 61.06%(138/226)였다. 예상 법령별 상위 10개를 합친 shortlist의 평균 gold Recall은 수정 CE 69.47%, Jev 74.63%로, Jev가 더 많은 정답 근거를 후속 선택 단계에 남겼다. 후보 목록당 하나를 선택하는 제약까지 고려할 때, 모든 gold를 동시에 선택할 수 있는 문항은 수정 CE 104개, Jev 120개였다. 이는 구조적으로 가능한 문항 수의 상한이다. 실제 완전 회수 문항은 각각 77개와 79개로 이보다 적었다. 따라서 최종 성능은 변경된 재정렬 결과와 공통 LLM 선택 절차가 결합된 파이프라인의 결과이다.

공개 코드 CE의 F1은 48.72점으로 수정 CE보다 9.85점 낮았다. 이 차이는 목록 참조 인덱스 수정에 따른 것으로, Jev 교체의 3.19점과 별개의 결과다. 문제를 확인한 범위는 공개 코드 스냅샷이며, 원 논문의 실제 실행에도 같은 문제가 있었는지는 확인되지 않았다.

## 4.3 질문 조건에 따른 성능 차이

근거 F1의 개선은 2ㆍ3-hop에서 나타났으며, 1-hop에서는 수정 CE가 소폭 높았다([그림 1](#fig-ch4-hop-f1)). 1-hop 57문항의 F1은 수정 CE 78.07점, Jev 76.90점으로 Jev가 1.17점 낮았다. 2-hop 127문항에서는 53.33점에서 57.24점으로 3.91점, 3-hop 42문항에서는 47.91점에서 54.83점으로 6.92점 높았다. 2ㆍ3-hop의 차이는 기술통계의 패턴이며, 층 간 효과 차이에 대한 상호작용 검정은 수행하지 않았다. 여기서 공식 hop은 평가 자료의 구분으로, 개별 문항의 실제 gold 개수와는 다르다.

<a id="fig-ch4-hop-f1"></a>

![공식 hop별 최종 근거 F1](figures/hop_f1.png)

**그림 1. 공식 hop별 최종 근거 F1. 표본 수는 각각 57, 127, 42문항이다. 점은 기술통계이며 층별 신뢰구간은 산출하지 않았다.**

3-hop의 평균 F1이 높아져도 완전 회수는 두 조건 모두 1문항(1/42, 2.38%)에 머물렀다. 평균 F1의 증가가 모든 정답 근거의 확보로 이어지지는 않았다.

매핑 상태에 따른 성능 차이도 컸다. 전역 고유 gold 386개 중 27개가 corpus와 정확히 매핑되지 않아 29문항에 영향을 주었다. 완전 매핑된 197문항의 F1은 수정 CE 64.12점, Jev 67.21점이었으며, 영향을 받은 29문항에서는 각각 20.80점과 24.71점이었다. 두 집단에서 Jev의 점추정이 높았으나, 문자열 일치 점수는 gold 외 근거의 법률적 타당성까지 평가하지는 못한다. 이 진단은 29문항을 포함한 전체 분석을 보완한다.

문항별 F1은 대부분 같았고, 차이가 난 문항에서는 개선과 악화가 함께 관찰되었다. 반올림 전 차이에 10⁻¹²의 동률 허용오차를 적용했을 때, Jev가 높은 문항은 32개, 같은 문항은 177개, 수정 CE가 높은 문항은 17개였다. 평균 개선은 이처럼 일부 문항의 변화에서 발생했다. 이 개수는 sourceㆍgold를 공유하는 문항들의 대응 결과를 기술하며, 독립 시행의 성공률을 뜻하지 않는다.

## 4.4 자동 답변 품질 및 자원 사용 특성

Jev 조건에서는 최종 답변의 자동 평가 점수도 높았다 ([표 2](#tab-ch4-main-results) 하단). LF-Eval은 수정 CE 67.57점에서 Jev 70.15점으로 2.58점 증가하였으며, 차이의 탐색적 95% 신뢰구간은 [+0.37, +4.79]점이었다. Token F1은 46.20점에서 47.31점으로 1.12점 증가하였고, 차이의 탐색적 95% 신뢰구간은 [+0.02, +2.27]점이었다.

Token F1은 정규화한 답변과 정답의 공백 토큰 중복을 측정하며, 생성 모델의 사용량 토큰과는 정의가 다르다. 공식 코드와 같은 800자 평가 규칙을 적용하였다. 이 지표의 centered-bootstrap 양측 p값은 약 0.0525였다. percentile 구간과 해당 검정은 동일 방법의 구간ㆍ검정 쌍이 아니므로, 자동 지표 전체를 통계적으로 유의한 개선으로 묶어 해석하지 않았다.

LF-Eval은 공식 정답 답변과 정답 근거(gold context)를 기준으로 한 평가이다. 실제 제공한 근거가 답변의 주장을 지지하는지는 별도의 사람 평가가 필요하다. 기존 60문항ㆍ세 조건의 총 180답변에 대한 블라인드 양식은 준비되었으나 실제 판단은 아직 없다. 따라서 사람 정확도ㆍ근거 지지율ㆍ평가자 일치도는 미측정 상태이며, 본 절의 품질 결과는 완료된 자동 평가에 한정된다.

자동 점수의 증가와 함께 평균 문맥ㆍ입력량도 소폭 늘었다. 문맥 토큰의 평균은 수정 CE 203.67개, Jev 215.60개였으며, 중앙값은 각각 164개와 170.5개, 사분위 범위(IQR)는 133.75개와 142.50개였다. 문항별 Jev-수정 CE의 대응 차이는 평균 +11.93개, 중앙값 0개, IQR 2.50개였다. 질문ㆍ지시문ㆍ예시까지 포함한 전체 API 입력 토큰은 평균 2302.67개와 2314.58개, 출력 토큰은 72.16개와 73.98개였다. 평균 입력량의 절감은 관찰되지 않았으며, 이 기술통계는 문맥 길이가 품질 차이의 원인임을 보여주는 결과도 아니다.

두 조건의 선택 목록 길이는 문항별로 같았으며, 각 조건의 합계는 478개였다. 문항 내 고유 근거 수의 합계는 각각 407개와 409개, 중복 출현은 71회와 69회였다. 선택 개수를 줄이는 Filtering을 적용한 결과가 아니라 선택 내용과 중복 양상의 차이이다. 문맥 토큰은 실제 제공 목록의 순서와 중복을 유지하고 줄바꿈으로 연결한 문자열에 `o200k_base` 토크나이저를 적용해 산출하였다. 전체 입력ㆍ출력량은 생성 응답의 사용량 기록을 사용하였다.

이 사용량은 생성 단계의 입출력 요구량으로, 신규 청구액과 구별된다. 생성 응답 캐시를 재사용한 문항은 수정 CE 72개, Jev 122개였으며, 캐시 행도 동일 입력이 요구하는 양을 기술하는 데 포함하였다. 선택ㆍ점수화ㆍ평가ㆍ재시도와 로컬 CE의 운영 단가를 모두 반영한 독립 서비스 비용은 산출하지 않았다. 캐시와 요청 제한 대기가 포함된 이번 품질 실행의 시간도 공정한 온라인 지연 비교에 사용할 수 없다.

## 4.5 오류 유형 및 관측 사례

Jev는 shortlist에서의 gold 탈락을 줄였으나, 이후 최종 선택되지 않는 gold도 남았다. 문항별 고유 gold 출현 443건의 최초 탈락 단계를 보면, BM25 후보에는 있지만 shortlist에서 탈락한 gold는 수정 CE 42건, Jev 13건이었다. shortlist에 남았으나 최종 선택되지 않은 gold는 각각 60건과 72건이었고, 최종 잔존은 233건과 250건이었다. 앞선 단계의 corpus 부재 33건과 공통 BM25 후보 부재 75건은 두 조건에서 같았다. 각 조건의 최초 탈락과 잔존을 합하면 443건이며, 이는 전역 고유 gold 386개와 다른 출현 단위 집계다.

이 단계별 집계는 exact gold의 회수ㆍ선택 상태를 설명한다. shortlist 내 미선택에는 후보 목록당 하나를 고르는 제약과 중복 선택이 관련될 수 있어, 이를 곧바로 LLM의 법률 판단 오류로 볼 수는 없다. gold 외 근거가 추가된 문항은 수정 CE 126개, Jev 116개였다. gold 외 근거의 법률적 무관성은 이 집계로 판정할 수 없으며, 문항 수준의 관측 유형도 서로 겹치므로 빈도의 합은 전체 오류 문항 수가 아니다.

대표 사례는 Jev 개선, 수정 CE 우세, 지표 불일치 묶음에서 근거 F1 차이 절댓값의 중앙값에 가장 가까운 문항을 선정하고, 동률은 query_id 사전순으로 정하였다. [표 3](#tab-ch4-cases)는 이 규칙으로 고른 세 사례의 자동 점수를 보여준다.

<a id="tab-ch4-cases"></a>

**표 3. 대표 관측 사례의 자동 점수 변화 (수정 CE → Jev)**

| 사례 | 질문 주제 | 근거 F1 | LF-Eval |
| --- | --- | --- | --- |
| A | 식품 보고 | 50.00 → 100.00 | 65.29 → 99.18 |
| B | 복수 청구 | 80.00 → 40.00 | 71.79 → 52.67 |

사례 A에서는 정답 근거의 완전 회수와 답변 문구의 변화가 함께 나타났다. 식품 생산실적과 위해식품 회수계획의 보고 상대방을 묻는 2-hop 문항으로, 수정 CE는 식품위생법 제42조제2항과 생산실적 관련 시행규칙을 선택하였다. Jev는 gold인 제42조제2항과 제45조제1항을 모두 선택하였으며, 답변에 회수계획의 보고 상대방으로 시장ㆍ군수ㆍ구청장을 포함하였다. 이 문항에서는 근거 F1과 LF-Eval이 모두 높아졌다.

사례 B에서는 Jev의 shortlist에서 gold가 탈락하고 두 자동 점수가 낮아졌다. 여러 당사자를 상대로 복수 청구를 제기하는 절차에 관한 2-hop 문항으로, 수정 CE는 gold인 민사소송법 제79조제1항과 제253조를 모두 선택하였다. Jev에서는 제79조제1항이 shortlist에서 탈락하고 최종 근거에 제83조제1항이 포함되었다. 답변은 각각 독립당사자참가와 공동소송참가 관련 내용을 담았으며, 근거 F1과 LF-Eval은 모두 수정 CE가 높았다. 각 제도의 실제 적용 가능성은 별도 법률 검토가 필요하다.

사례 C에서는 근거 F1과 답변 Token F1이 반대 방향으로 변했다. 사면과 복수 범죄의 처리에 관한 3-hop 문항으로, gold 3개 중 하나는 corpus에 정확히 매핑되지 않았고 다른 하나는 BM25 후보에 없었다. 생성된 후보 목록도 2개였다. 수정 CE는 gold 하나를 최종 선택했으나 Jev는 exact gold를 선택하지 않았다. 답변 Token F1은 18.60점에서 25.88점으로 높아져, 문자열 중복의 증가가 정답 근거 회수의 증가와 일치하지 않는 사례를 보여준다. 사면 유형, 범죄의 경합 관계, gold 외 선택 조문의 타당성은 전문가 검토 사항이다.

세 사례는 법률 전문가의 판정이 완료되지 않은 자동 관측 사례이다. 모두 기존 사람 평가 60문항 표본 밖의 별도 정성 검토 대상으로, 블라인드 표본을 교체하거나 사람 평가 결과에 추가하지 않았다. 법률적 오류 여부와 제공 근거의 주장 지지는 미판정 상태이다.
