검토일: 2026-11-09.

요청 경로 `research/chapter4/style-study-v1/cahpter4.md`는 존재하지 않았다. 실제 Markdown 편집본인 [chapter4.md](../chapter4.md)를 검토·수정하였다. 수정 전 본문은 [before-readability/chapter4.md](before-readability/chapter4.md)에 보존하였다.

## 검토 판단

기존 원고는 주요 결과와 해석의 한계를 명확히 제시했지만, 실험 배경을 아는 독자를 전제하고 있었다. 처음 읽는 독자는 무엇을 교체한 실험인지, 후보 목록과 최종 근거가 어떻게 다른지, 평균 점수 개선과 완전 회수의 차이가 무엇인지 이해하기 전에 수치를 접하게 된다. 실험 내용과 수치는 유지하면서 개념 설명과 제시 순서를 보완하였다.

| 처음 읽을 때 막히는 부분 | 수정 내용 |
| --- | --- |
| KoBLEX·ParSeR·CE·Jev의 역할이 한 문장에 압축됨 | 평가 자료와 비교 대상의 역할을 설명하고, 예상 법령 생성→검색→재정렬→선택→답변 생성의 다섯 단계로 풀어 씀 |
| ‘예상 법령’, ‘gold’, ‘shortlist’, ‘corpus’가 설명 없이 등장함 | 각 용어가 처음 쓰이는 문맥에서 뜻을 밝히고, 모델의 예상과 평가 정답을 구별함 |
| 선택 인덱스 문제가 무엇인지 알기 어려움 | 선택 번호를 현재 목록 대신 첫 목록에 적용하는 문제라고 설명하고, 수정 CE와 Jev의 주 비교를 분리함 |
| F1·Recall·EM·모든 gold 포함률의 차이가 불분명함 | 결과보다 먼저 정의를 제시하고, 가상의 A·B·C 근거 예시로 부분 회수·완전 회수·EM의 차이를 설명함 |
| 151개 의존 그룹, bootstrap, CI가 압축되어 있음 | 문항을 묶는 이유, 두 조건을 짝짓는 방식, 그룹 복원추출과 구간 산출 방식을 설명함 |
| hop과 gold 개수, 매핑 불일치와 검색 실패를 혼동하기 쉬움 | 공식 hop 표기의 의미와 실제 gold 수의 차이, 동일 문자열이 corpus에 없는 경우의 평가 제약을 설명함 |
| Token F1과 사용량 토큰, LF-Eval과 실제 근거 지지 여부가 혼동됨 | 각 지표의 평가 대상과 단위를 먼저 밝히고, 자동 평가와 미실시 사람 평가의 경계를 유지함 |
| 자원 통계와 단계별 탈락 수치가 문장에 밀집됨 | 기존 수치를 표 3·4로 옮기고, 386개 고유 gold와 443건 문항별 출현의 차이를 집계 전에 설명함 |
| 사례 C가 왜 ‘지표 불일치’인지 표에서 확인하기 어려움 | 사례별 선정 유형을 표시하고, C는 근거 F1과 Token F1의 불일치임을 명시함 |

표를 추가하면서 사례 표는 표 5로 조정하였다. 근거 성능의 주요 해석은 그대로 유지하였다. Jev의 평균 F1·Recall은 높았지만 완전 회수의 차이는 불확실하고, 1-hop은 감소했으며, 3-hop의 완전 회수는 두 조건 모두 1문항이다. 자동 답변 점수는 사람의 법률 판단이나 실제 제공 근거의 주장 지지 판정을 대체하지 않는다. 입력량 절감, 전체 서비스 비용 또는 응답 지연의 우월성도 추가로 주장하지 않았다.

## 확인 범위

- 주요 성능 표의 모든 수치와 신뢰구간, 사례 표의 기존 점수, hop·매핑·문항별 비교 수치의 보존 여부를 대조하였다.
- 자원 표는 `manuscript-facts.json`의 기술통계, 단계별 표는 같은 원장의 탈락 건수와 대조하였다.
- 평가 정의와 800자 처리, LF-Eval 평가 기준, 인덱스 문제 설명은 로컬 평가 코드·평가 프롬프트·기존 실험 결과 기록과 대조하였다.
- 다섯 절, 다섯 표, 기존 그림, 내부 링크와 그림 경로를 확인하였다. 기계 확인 결과는 [readability-validation.json](readability-validation.json)에 기록하였다.

이번 수정의 본문 대상은 Markdown이다. LaTeX·PDF는 이전 문체 수정 상태이며, 기존 `validation.json`은 이번 Markdown 수정의 검증 기록이 아니다. `tmp/chapter4_to_markdown.py`를 다시 실행하면 LaTeX에서 재생성되어 이번 편집을 덮어쓰므로 주의가 필요하다. 실험 원자료·수치 원장·LaTeX·그림의 변경 여부는 [수정 전 해시 원장](before-readability/manifest.json)과 대조하였다.

새 실험·추가 통계 검정·사람 평가·외부 문헌 조사는 수행하지 않았다. 검토는 원고의 설명과 논리 흐름을 기준으로 한 편집 검토이며, 실제 초독자 대상 이해도 시험을 수행한 것은 아니다.
