# 4. 실험 결과 및 분석

## 4.1 실험 조건 및 비교 기준

본 장은 한국어 법률 질의응답 벤치마크 KoBLEX의 공식 한국어 226문항에서, ParSeR의 재정렬 모델을 CE(cross-encoder)에서 Jev로 교체했을 때의 근거 선택 성능과 답변 품질을 비교한다. KoBLEX와 ParSeR은 [Lee et al. (2025)](https://arxiv.org/abs/2509.01324)의 자료와 방법을 따른다. CE와 Jev는 질문과 후보 법령의 관련도를 점수화하여 후속 선택기에 제공할 후보 순서를 정한다. 주 비교는 공개 코드의 후보 목록 참조 문제를 수정한 CE와 동일한 절차에 Jev를 적용한 조건 간의 문항별 대응 비교이다. 공개 코드 CE는 수정 전 동작을 보존한 재현 참조 조건으로 두었다([표 1](#tab-ch4-conditions)).

<a id="tab-ch4-conditions"></a>

**표 1. 비교 조건. 수정 CE와 Jev는 후보 목록 참조 방식을 동일하게 수정하고 점수화 모델만 달리하였다.**

| 조건 | 점수화 모델 | 후보 목록 참조 | 역할 |
| --- | --- | --- | --- |
| 공개 코드 CE | BGE 계열 CE | 공개 코드의 문제 보존 | 재현 참조 |
| 수정 CE | BGE 계열 CE | 수정 | 주 기준선 |
| Jev 교체 | Jev | 수정 | 주 비교 |

세 조건은 질문과 배경에서 생성한 예상 법령 문구 및 이를 이용한 BM25 검색 후보를 공유하였다. 예상 법령별 후보 100개를 재정렬하여 상위 10개 목록(shortlist)을 구성하고, 공통 대규모 언어 모델(LLM) 선택기가 목록마다 하나의 근거를 선택한 뒤 이를 이용해 답변을 생성하였다. 선택 목록의 길이는 예상 법령 수에 따라 달라지며, 평가 자료의 추론 단계 구분인 hop 정보는 선택 개수를 정하는 데 사용하지 않았다. CE는 `bge-reranker-v2-m3-ko`, Jev는 `jev-1.14.0`을 사용하였고, 근거 선택·답변 생성·LF-Eval의 모델은 `gpt-4o-2024-08-06`으로 통일하였다. 선택·생성 프롬프트와 평가 기준도 동일하게 유지하였다.

근거 선택은 공식 정답 근거(gold)와 최종 선택 근거의 문자열 집합을 비교하여 평가하였다. Recall은 gold 중 선택된 비율이고, F1은 선택 근거의 정밀도와 Recall의 조화평균이다. EM은 두 집합이 정확히 같은 문항의 비율이며, 모든 gold 포함률은 추가 근거의 유무와 관계없이 gold를 모두 선택한 문항의 비율이다. 이후 이를 완전 회수라고 부른다. F1과 Recall은 문항별 점수의 비가중 평균으로 집계하였다. 답변 품질은 정답 답변과의 공백 토큰 중복을 측정하는 Token F1과, 정답 답변 및 gold를 기준으로 LLM이 평가하는 LF-Eval로 측정하였다. 세부 평가 절차는 [보충자료 S1](chapter4-supplement.md#s1-evaluation)에 제시하였다.

일부 gold를 검색 대상 법령 자료(corpus)의 동일 문자열에 대응시킬 수 없는 29문항도 제외하지 않고 전체 226문항을 주 분석에 포함하였다. 모든 비교는 기존 시험 결과를 확인한 이후 수행한 탐색적 재현 분석이다.

## 4.2 재정렬 모델 교체에 따른 근거 선택 성능

Jev의 최종 근거 F1은 61.75점으로 수정 CE의 58.57점보다 3.19점 높았으며, Recall은 2.95점 높았다([표 2](#tab-ch4-main-results)). 두 차이의 탐색적 95% 신뢰구간은 각각 [+0.75, +5.68]점과 [+0.39, +5.51]점이었다. 반면 완전 회수 문항은 수정 CE 77개에서 Jev 79개로 늘어나는 데 그쳤다. 평균적인 근거 회수는 개선되었지만, 모든 정답 근거를 확보하는 성능에서는 뚜렷한 차이를 확인하기 어려웠다.

<a id="tab-ch4-main-results"></a>

**표 2. 수정 CE와 Jev의 근거 선택 및 자동 답변 품질 비교 (n=226). Δ는 Jev−수정 CE이며, 구간은 그 차이의 탐색적 95% 신뢰구간이다.**

| 지표 | 수정 CE | Jev | Δ | 차이의 95% CI |
| --- | --- | --- | --- | --- |
| **근거 선택** |  |  |  |  |
| F1 | 58.57 | 61.75 | +3.19 | [+0.75, +5.68] |
| Recall | 57.74 | 60.69 | +2.95 | [+0.39, +5.51] |
| EM | 27.88 | 29.65 | +1.77 | [-1.77, +5.19] |
| 모든 gold 포함률 | 34.07 | 34.96 | +0.88 | [-2.90, +4.53] |
| **답변 품질** |  |  |  |  |
| Token F1 | 46.20 | 47.31 | +1.12 | [+0.02, +2.27] |
| LF-Eval | 67.57 | 70.15 | +2.58 | [+0.37, +4.79] |

주: 값은 0–1 원점수의 100배이며, EM과 모든 gold 포함률은 백분율이다. EM과 모든 gold 포함률의 차이는 %p, 나머지 차이는 점 단위이다. 차이와 구간은 반올림 전 값으로 계산하였다. 같은 출처나 gold를 공유하는 문항을 묶은 151개 의존 그룹에 대해 대응 bootstrap 10,000회의 percentile 구간을 산출하였으며, 다중 비교는 보정하지 않았다.

EM과 모든 gold 포함률의 차이는 모두 신뢰구간에 0을 포함하였다. EM의 증가폭은 1.77%p였고, 모든 gold 포함률의 증가폭은 0.88%p로 신뢰구간은 [-2.90, +4.53]%p였다. 이는 평균 F1·Recall의 개선과 근거 집합의 완결성 개선을 구별해야 함을 보여준다.

Jev의 회수 이점은 최종 선택 이전의 shortlist에서도 관찰되었다. 예상 법령별 상위 10개를 합친 shortlist의 평균 gold Recall은 수정 CE 69.47%, Jev 74.63%였다. 재정렬 전 공통 BM25 후보 합집합의 평균 gold Recall은 77.21%, 모든 gold 포함률은 61.06%(138/226)였다. Jev는 공통 검색 후보에 포함된 gold를 상위 후보로 더 많이 보존하였다.

그러나 shortlist에 남은 gold가 모두 최종 선택으로 이어지지는 않았다. 후보 목록당 하나만 선택하는 제약을 고려하면, 완전 회수가 가능한 문항 수의 상한은 수정 CE 104개, Jev 120개였으나 실제 완전 회수는 각각 77개와 79개였다. 동일 목록에 여러 gold가 포함되면 전부 선택하지 못할 수 있으며, 서로 다른 목록에서 같은 근거를 선택할 수도 있다. 따라서 최종 성능은 변경된 재정렬 결과와 공통 LLM 선택 절차가 결합된 결과이다.

공개 코드 CE의 F1은 48.72점으로 수정 CE보다 9.85점 낮았다. 이 차이는 후보 목록 참조 문제의 수정에 따른 것으로, Jev 교체의 3.19점과 별개의 결과이다. 문제를 확인한 범위는 공개 코드 스냅샷이며, 원 논문의 실제 실행에도 같은 문제가 있었는지는 확인되지 않았다. 참조 문제의 세부 내용은 [보충자료 S2](chapter4-supplement.md#s2-reference)에 기술하였다.

## 4.3 질문 조건에 따른 성능 차이

근거 F1의 개선은 2·3-hop에서 나타났으며, 1-hop에서는 수정 CE가 소폭 높았다([그림 1](#fig-ch4-hop-f1)). 여기서 hop은 평가 자료가 부여한 추론 단계 구분으로, 개별 문항의 실제 gold 개수와 항상 같지는 않다. 1-hop 57문항의 F1은 수정 CE 78.07점, Jev 76.90점으로 Jev가 1.17점 낮았다. 2-hop 127문항에서는 53.33점에서 57.24점으로 3.91점, 3-hop 42문항에서는 47.91점에서 54.83점으로 6.92점 높았다.

<a id="fig-ch4-hop-f1"></a>

![공식 hop별 최종 근거 F1](figures/hop_f1.png)

**그림 1. 공식 hop별 최종 근거 F1. 1·2·3-hop의 표본 수는 각각 57, 127, 42문항이다. 각 점은 문항 평균이며, 집단별 신뢰구간은 산출하지 않았다.**

이 패턴은 관측된 평균의 차이이며, hop 집단 간 모델 교체 효과의 차이에 대한 상호작용 검정은 수행하지 않았다. 또한 3-hop의 완전 회수는 두 조건 모두 1문항(1/42, 2.38%)에 머물렀다. 평균 F1의 증가에도 여러 정답 근거를 모두 확보하는 데에는 제약이 남았다.

gold의 매핑 상태에 따른 성능 차이도 컸다. 전체 문항에서 중복을 제거한 gold 386개 중 27개는 corpus에서 동일한 문자열을 찾을 수 없어 29문항에 영향을 주었다. 모든 gold가 매핑된 197문항의 F1은 수정 CE 64.12점, Jev 67.21점이었으며, 영향을 받은 29문항에서는 각각 20.80점과 24.71점이었다. 두 집단에서 Jev의 관측 평균이 높았으나, 매핑 불일치 집단의 낮은 점수에는 동일 문자열을 회수할 수 없는 자료 제약도 반영된다. 이 진단은 해당 문항을 포함한 전체 분석을 보완한다.

문항별 F1은 177문항에서 같았고, Jev가 높은 문항은 32개, 수정 CE가 높은 문항은 17개였다. 따라서 전체 평균의 개선은 일부 문항의 변화에서 발생하였다. 동률은 반올림 전 차이에 10⁻¹²의 허용오차를 적용하여 판정하였다. 이 집계에는 출처나 gold를 공유하는 문항이 포함되므로, 독립 시행의 성공률로 해석할 수는 없다.

## 4.4 자동 답변 품질 및 자원 사용 특성

### 4.4.1 자동 답변 품질

Jev 조건에서는 LF-Eval과 Token F1도 높았다([표 2](#tab-ch4-main-results)). LF-Eval의 증가폭은 2.58점으로 탐색적 95% 신뢰구간은 [+0.37, +4.79]점이었고, Token F1의 증가폭은 1.12점으로 신뢰구간은 [+0.02, +2.27]점이었다. 근거 선택뿐 아니라 정답 기준의 자동 답변 평가에서도 평균 점수가 증가하였다.

다만 Token F1의 centered-bootstrap 양측 p값은 약 0.0525였다. 표의 percentile 구간과 이 검정은 동일 방식의 구간·검정 쌍이 아니므로, 구간이 0보다 높다는 이유로 자동 지표 전체를 통계적으로 유의한 개선으로 묶어 해석하지 않았다.

LF-Eval은 시스템이 실제로 제공한 근거가 아닌 공식 gold를 기준으로 답변을 평가한다. 따라서 점수의 증가가 실제 제공 근거의 주장 지지까지 의미하지는 않는다. 사람 평가는 수행되지 않았으므로, 사람이 판정한 답변 정확도·근거 지지율·평가자 간 일치도는 미측정 상태이다.

### 4.4.2 답변 생성의 입력 요구량

Jev의 자동 답변 점수 증가는 평균 입력량의 절감과 동반되지 않았다. 답변 생성에 제공한 선택 근거인 문맥의 토큰 수는 수정 CE 평균 203.67개에서 Jev 215.60개로 늘었다([표 3](#tab-ch4-resources)). 문항별 대응 차이는 평균 +11.93개, 중앙값 0개, 사분위 범위(IQR) 2.50개였다. 이는 문맥 길이와 품질이 함께 변했다는 관측이며, 문맥 길이가 품질 차이의 원인임을 뜻하지 않는다.

주: 문맥은 선택 근거 목록의 순서와 중복을 유지하여 집계하였다. 전체 API 입력에는 질문·지시문·예시가 포함된다. IQR은 제3사분위수와 제1사분위수의 차이이다. 사용량 토큰은 Token F1의 공백 토큰과 구별된다.

두 조건의 선택 목록 길이는 문항별로 같았으며, 전체 선택 항목은 조건별 478개였다. 문항마다 중복을 제거한 근거 수의 합은 수정 CE 407개, Jev 409개였고, 중복 출현은 각각 71회와 69회였다. 따라서 관측된 차이는 선택 개수를 줄이는 필터링(Filtering)의 결과가 아니라 선택 내용과 중복 양상의 변화이다.

이 비교는 생성 단계의 입출력 요구량에 한정된다. 근거 선택·점수화·평가·재시도 및 로컬 CE 운영비까지 반영한 조건별 서비스 비용은 산출하지 않았다. 캐시 재사용과 요청 제한 대기가 포함된 실행 시간도 실제 서비스의 응답 지연 비교에 사용할 수 없다. 토큰 산출 방식과 캐시 집계는 [보충자료 S3](chapter4-supplement.md#s3-usage)에 제시하였다.

## 4.5 오류 유형 및 관측 사례

Jev는 shortlist에서의 gold 탈락을 줄였지만, 후속 선택에서 활용되지 못한 gold도 남았다([표 4](#tab-ch4-stages)). BM25 후보에는 있으나 shortlist에서 탈락한 gold는 수정 CE 42건에서 Jev 13건으로 줄었고, 최종 선택에 포함된 gold는 233건에서 250건으로 늘었다. 반면 shortlist에 남았으나 선택되지 않은 gold는 60건에서 72건으로 늘었다.

| shortlist에는 있으나 최종 선택되지 않음 | 60건 | 72건 |
| 최종 선택에 포함 | 233건 | 250건 |
| 합계 | 443건 | 443건 |

주: 한 문항 안에서는 같은 gold를 한 번만 세고, 다른 문항에도 등장하면 각각 센다. 따라서 443건은 전체 문항에서 중복을 제거한 고유 gold 386개와 다르다.

corpus와 BM25 후보는 두 조건이 공유하므로 앞선 두 단계의 탈락 건수는 같았다. shortlist 내 미선택에는 목록당 하나를 고르는 제약과 중복 선택이 관련될 수 있어, 이를 곧바로 LLM의 법률 판단 오류로 볼 수는 없다. gold 외 근거가 선택된 문항은 수정 CE 126개, Jev 116개였다. 이 집계는 문자열 일치 상태를 나타내며, gold 외 근거의 법률적 타당성은 판정하지 않는다.

선택 근거와 답변의 변화를 살펴보기 위해 Jev 개선, 수정 CE 우세, 근거·답변 지표 불일치 집단에서 각각 한 사례를 선정하였다([표 5](#tab-ch4-cases)). 각 사례는 집단 내 근거 F1 차이 절댓값의 중앙값에 가장 가까운 문항이며, 전체 문항을 대표하는 통계적 표본은 아니다. 사례 식별자와 선정 세칙은 [보충자료 S4](chapter4-supplement.md#s4-cases)에 제시하였다.

<a id="tab-ch4-cases"></a>

**표 5. 선정한 관측 사례의 근거 선택 및 자동 답변 점수 (수정 CE → Jev). 모든 점수는 0–100 척도이다.**

| 사례 | 질문 주제 | 근거 F1 | Token F1 | LF-Eval |
| --- | --- | --- | --- | --- |
| A | 식품 보고 | 50.00 → 100.00 | 69.09 → 86.79 | 65.29 → 99.18 |
| B | 복수 청구 | 80.00 → 40.00 | 32.79 → 29.09 | 71.79 → 52.67 |
| C | 사면 효과 | 40.00 → 0.00 | 18.60 → 25.88 | 31.10 → 30.55 |

주: A는 Jev 개선, B는 수정 CE 우세, C는 근거 F1과 Token F1의 변화 방향 불일치를 보여준다.

사례 A에서는 gold의 완전 회수와 답변 내용의 변화가 함께 나타났다. 식품 생산실적과 위해식품 회수계획의 보고 상대방을 묻는 2-hop 문항으로, 수정 CE는 식품위생법 제42조제2항과 생산실적 관련 시행규칙을 선택하였다. Jev는 gold인 제42조제2항과 제45조제1항을 모두 선택하고, 답변에 회수계획의 보고 상대방으로 시장·군수·구청장을 포함하였다. 근거 F1과 두 답변 지표가 모두 높아진 사례이다.

사례 B에서는 Jev의 shortlist에서 gold가 탈락하고 답변 지표도 낮아졌다. 여러 당사자를 상대로 복수 청구를 제기하는 절차에 관한 2-hop 문항으로, 수정 CE는 gold인 민사소송법 제79조제1항과 제253조를 모두 선택하였다. Jev에서는 제79조제1항이 shortlist에서 탈락하고 최종 근거에 제83조제1항이 포함되었다. 수정 CE 답변은 독립당사자참가, Jev 답변은 공동소송참가에 관한 내용을 담았으며, 근거 F1과 두 답변 지표는 모두 수정 CE가 높았다.

사례 C에서는 근거 F1이 낮아졌으나 Token F1은 높아졌다. 사면과 복수 범죄의 처리에 관한 3-hop 문항으로, gold 3개 중 하나는 corpus에 정확히 매핑되지 않았고 다른 하나는 BM25 후보에 없었다. 후보 목록도 2개여서 현재 선택 규칙으로는 gold 3개를 모두 선택할 수 없었다. 수정 CE는 gold 하나를 선택했으나 Jev는 gold와 문자열이 일치하는 근거를 선택하지 않았다. 그럼에도 답변 Token F1은 높아져, 정답과의 표현 중복 증가가 정답 근거 회수 증가와 일치하지 않을 수 있음을 보여준다.

세 사례는 자동 관측에 기반한 것으로, 법률적 정오와 제공 근거의 주장 지지는 미판정 상태이다. 특히 사례 B의 절차 제도 적용 가능성, 사례 C의 사면 유형·범죄 경합 관계 및 gold 외 선택 조문의 타당성은 전문가 검토가 필요하다.
