# 제4장 최종 구성안 — 지연 벤치마크 완료를 전제로

## 구성 검토와 확정

5개 절과 RQ1→RQ2→RQ3 순서는 유지한다. 4.2는 전체 파이프라인의 최종 근거 선택 성능, 4.3은 재정렬 단계의 품질·지연 비교로 역할을 나눈다. 지연 결과의 방향에 따라 제목을 바꾸거나 우월성을 전제하지 않는다.

현재 증거 범위에 맞춰 다음 절 제목을 제4장 집필 기준으로 확정한다. 이는 제1장·제3장 담당자와의 합의 완료를 의미하지 않으며, RQ 문구·방법 설명도 이 측정 범위에 맞춰야 한다.

- **4.1 실험 조건 요약**
- **4.2 Decision Model 적용에 따른 근거 선택 성능 변화 (RQ1)**
- **4.3 Decision Model과 Cross-Encoder의 재정렬 성능·지연시간 비교 (RQ2)**
- **4.4 최종 답변의 자동 품질과 자원 사용 특성 (RQ3)**
- **4.5 오류 유형 및 사례 분석**

원안의 ‘검색 성능’은 최종 근거 선택의 측정 지점이 모호해 구체화했다. ‘정확도’는 후보별 관련성 분류 accuracy를 측정한 것으로 오해할 수 있어 재정렬 성능으로 바꿨다. ‘효율성과 근거 충실도’는 지연 결과가 나와도 직접 입증되지 않는다. 지연 측정은 답변 생성과 전체 파이프라인을 포함하지 않으며 LF-Eval은 정답 근거를 기준으로 평가한다. 실제 제공 근거가 답변의 주장을 지지하는지는 사람 평가가 필요하다. 효율성 개선이 관찰되지 않아도 결과를 보고할 수 있지만, 현재 RQ3의 두 개념을 직접 측정한 것으로 쓰지 않는다.

## 4.1 실험 조건 요약

- 목적: ParSeR의 재정렬 scorer를 CE에서 Jev로 교체했을 때 근거 선택·단계 지연·최종 답변에 어떤 변화가 생기는지 평가.
- 조건: 공개 코드 CE는 참조, 수정 CE는 주 기준선, Jev는 주 비교. 인덱스 수정 효과와 scorer 교체 효과를 분리.
- 공통 통제: 한국어 QA 226문항, 같은 예상 법령·BM25 후보, 후보 100개→상위 10개→pool별 LLM 1개 선택, 동일 생성·평가 모델 및 프롬프트.
- 모델: bge-reranker-v2-m3-ko, jev-1.14.0, gpt-4o-2024-08-06. 세부 revision·환경은 방법/보충자료 참조.
- 평가 분모: 품질 226문항, 지연 사전 지정 표본 60문항(1/2/3-hop 15/34/11), 방법별 3회 반복. 사람 평가는 양식만 준비되어 있음.
- 분석 성격: 사후 탐색, 품질 비교 151그룹 대응 bootstrap 10,000회, 다중 비교 무보정. 지연도 표본에 해당하는 의존 그룹을 유지하며 반복을 독립 문항으로 세지 않음.
- 배치: 조건 비교 소표 1개. 제3장의 상세 방법을 반복하지 않음.

## 4.2 Decision Model 적용에 따른 근거 선택 성능 변화 (RQ1)

- 질문: 동일한 검색 후보에서 Jev 적용이 최종 선택 근거의 정답 일치 수준을 높였는가?
- 주 결과: 근거 Precision·Recall·F1·EM·완전 회수율과 Jev−수정 CE 차이 및 탐색적 CI.
- 핵심 수치: F1 58.57→61.75(+3.19점), Recall 57.74→60.69(+2.95점). EM 27.88→29.65%, 완전 회수율 34.07→34.96%.
- 해석: 평균 F1·Recall의 개선과 모든 근거를 확보하는 문제를 구분. EM·완전 회수율 차이 CI는 0을 포함.
- 조건별 분석: hop별 F1(1-hop 78.07→76.90, 2-hop 53.33→57.24, 3-hop 47.91→54.83), 개선/동일/악화 32/177/17문항. 하위집단 효과 차이를 검정한 것으로 해석하지 않음.
- 데이터 영향: corpus 완전 매핑 197문항과 영향 29문항 보조 분석. 전체 226문항을 유지.
- 공개 코드 CE의 낮은 점수와 인덱스 수정의 F1 +9.85점은 별도 진단으로 짧게 기술하거나 보충자료로 이동.
- 배치: 최종 근거 성능표와 hop별 F1 그림. 답변 품질 결과는 4.4에 배치.

## 4.3 Decision Model과 Cross-Encoder의 재정렬 성능·지연시간 비교 (RQ2)

- 질문: 같은 후보를 상위 10개로 줄이는 단계에서 두 scorer의 정답 근거 유지 수준과 소요 시간은 어떻게 다른가?
- 품질 측정 지점: LLM 최종 선택 이전 shortlist. 문항별 shortlist 합집합 gold Recall, 모든 gold 포함률, 필요시 pool별 유지 비율을 분모와 함께 보고.
- 현재 품질 수치: shortlist 합집합의 문항별 평균 Recall은 CE 69.47%, Jev 74.63%. 전체 최종 근거 F1은 4.2를 참조하고 같은 결과를 반복 서술하지 않음.
- 지연 측정 범위: 문항별 고유 질문–후보 점수화와 pool별 정렬/top-10. BM25, 예상 법령 생성, LLM 선택, 답변 생성, 모델 로드 제외.
- 실행 조건: 캐시 비활성화, 두 방법 동일 중복 처리, 방법별 워밍업 3문항 제외, 60문항×2방법×3반복. CE는 MPS/batch 50, Jev는 원격 API/동시성 4.
- 완료 점검: 360개 본 측정의 실제 충족 여부, 실패·재시도·누락, 비교에 포함된 대응 문항 수, quality run 대비 top-10 재현 일치도. 반복 결과가 바뀌면 기존 품질 수치와의 결합 한계를 보고.
- 지연 결과: 문항별 3회 평균을 분석 단위로 삼아 평균·중앙값·IQR·p95를 보고. p95가 문항별 반복 평균의 분포에서 계산된 값임을 명시. 대응 평균 차이와 CI, Jev/CE 기하평균 비율과 CI를 보고하고 비율 방향을 표에 정의.
- 같은 60문항의 품질과 지연을 보조 표로 맞추면 직접 비교가 명료함. 필요 시 기존 원자료만 별도 집계하며 전체 226문항 품질과 표본 60문항 지연을 동일 분모처럼 표시하지 않음.
- 해석: 더 빠름/비슷함/느림 어느 결과든 품질과 함께 기술. 로컬 CE 대 원격 API라는 배포 조건의 비교이며 모델 고유 속도나 E2E 속도로 일반화하지 않음.
- 배치: 재정렬 품질·지연 표 1개. 숫자는 벤치마크 완료·무결성 확인 뒤 삽입.

## 4.4 최종 답변의 자동 품질과 자원 사용 특성 (RQ3)

- 질문: 근거 선택의 변화가 최종 답변의 자동 평가와 생성 입력 요구량에 어떻게 연결되는가?
- 자동 품질: Token F1 46.20→47.31(+1.12점), LF-Eval 67.57→70.15(+2.58점), 기존 대응 CI를 함께 보고.
- 지표 의미: Token F1은 공백 단위 표현 중복, LF-Eval은 정답 답변·정답 근거 기준 평가. 두 지표 모두 실제 제공 근거에 대한 주장 지지를 직접 측정하지 않음.
- 통계 한계: Token F1 percentile CI와 별도 centered-bootstrap p≈0.0525의 산출 방식 차이를 보존. 모든 지표가 유의하게 개선됐다고 요약하지 않음.
- 자원 요구량: 문맥 평균 토큰 203.67→215.60, 전체 API 입력 2302.67→2314.58, 출력 72.16→73.98. 중앙값·IQR·대응 차이를 필요한 만큼 병기.
- 선택 수·중복: 조건별 선택 목록 478개로 동일. 문항 내 고유 선택 합계 CE 407/Jev 409, 중복 71/69회. 근거 수 감소 실험과 구분.
- 현재 결론: 자동 답변 품질의 평균은 높아졌으나 입력량 절감은 관찰되지 않음. 캐시 재사용량을 신규 청구량으로 합산하지 않고 전체 서비스 비용·전체 답변 지연은 미측정으로 명시.
- 필터링은 별도 탐색 분석으로 짧게 소개하거나 부록 배치: Jev 근거 478→426개(89.12% 유지), 근거 F1 61.75→61.43, Precision 증가·Recall 감소. 답변 재생성·재평가가 없어 답변 품질 유지·실제 비용 절감·비열등성의 증거로 쓰지 않음.
- 사람 근거 충실도: 실제 독립 제출이 완료될 경우 정확성·선택 근거 지지 점수·미지지 법률 주장 비율·평가자 일치도를 별도 결과로 추가 가능. 지연 결과만 나온 현재 전제에서는 수치를 채우지 않음.
- 배치: 자동 답변 품질·자원 사용 표 1개. 필터링 상세 곡선·fold별 문턱값은 보충자료.

## 4.5 오류 유형 및 사례 분석

- 질문: 개선·악화가 어느 단계에서 생기며 자동 근거 점수와 답변 점수가 언제 어긋나는가?
- 단계별 정량 집계: 문항별 gold 출현 443건/조건을 최초 탈락 또는 최종 선택 상태로 분류.
- 공통 제약: corpus 미매핑 33건, BM25 미회수 75건. 전역 고유 미매핑 27개·영향 29문항과 분모가 다름.
- scorer 이후 변화: shortlist 탈락 CE 42/Jev 13건, shortlist 잔존 후 미선택 60/72건, 최종 선택 233/250건.
- 구조적 제약: pool당 하나 선택 때문에 shortlist에 gold가 모두 있어도 동시에 모두 고를 수 없을 수 있음. 미선택을 곧바로 LLM의 법률 판단 오류로 부르지 않음.
- 대표 사례 A(qa_124_2hop_480_rand): 식품 생산실적·회수계획 보고, F1 50→100, LF 65.29→99.18. 정답 근거 추가와 답변 변화 연결.
- 대표 사례 B(qa_324_2hop_515): 복수 당사자 청구 절차, F1 80→40, LF 71.79→52.67. 정답 근거의 shortlist 탈락과 악화 연결.
- 대표 사례 C(qa_443_3hop_703): 사면·복수 범죄, F1 40→0인데 Token F1 18.60→25.88. 후보 제약·표현 중복 지표의 한계 설명.
- 사례 선정 규칙: 개선·CE 우세·지표 불일치 집단의 중앙적 사례, 동률 query_id 순. 자동 관측과 전문가 판정을 구별.
- 배치: 사례 요약표 또는 박스 1개. 긴 질문·조문·답변·ID·선정 규칙·법률 검토 대기는 보충자료.
