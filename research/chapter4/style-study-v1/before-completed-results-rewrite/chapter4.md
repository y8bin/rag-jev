# 4. 실험 결과 및 분석

## 4.1 실험 조건 및 비교 기준

KoBLEX의 한국어 법률 질문 226문항에서 ParSeR의 재정렬 모델을 CE(cross-encoder)에서 Jev로 교체하여 비교하였다. 재정렬 모델은 검색된 법령 후보에 질문과의 관련도 점수를 매겨 순서를 정하는 역할을 한다. 주 기준선은 공개 코드의 후보 목록 참조 오류를 수정한 CE이며, 오류를 보존한 CE는 재현 점검용으로 구분하였다([표 1](#tab-ch4-conditions)).

<a id="tab-ch4-conditions"></a>

**표 1. 비교 조건**

| 조건 | 점수화 모델 | 참조 오류 | 역할 |
| --- | --- | --- | --- |
| 공개 코드 CE | BGE | 보존 | 재현 점검 |
| CE | BGE | 수정 | 주 기준선 |
| Jev 교체 | Jev | 수정 | 주 비교 |

세 조건은 질문에서 예상한 법령 문구와 BM25 검색 후보를 공유하였다. 예상 법령별 후보 100개를 재정렬하고, 상위 10개 중 공통 언어 모델(LLM)이 하나를 선택한 뒤 답변을 생성하였다. 선택 개수는 예상 법령 수에 따르며 정답 정보로 정하지 않았다. 프롬프트와 평가 기준도 동일하게 유지하였다.

CE는 `bge-reranker-v2-m3-ko`, Jev는 `jev-1.14.0`을 사용하였다. 선택·생성·자동 평가 모델은 `gpt-4o-2024-08-06`이다. 정답 근거 일부가 검색 자료와 일치하지 않는 29문항도 전체 분석에 포함하였다. 모든 비교는 기존 시험 결과를 확인한 뒤 수행한 탐색적 분석이다.

## 4.2 재정렬 모델 교체에 따른 근거 선택 성능

Jev의 근거 F1은 61.75점으로 CE보다 3.19점 높았고, Recall은 2.95점 높았다([표 2](#tab-ch4-main-results)). F1은 정답 근거의 누락과 정답 외 근거의 선택을 함께 반영하며, Recall은 정답 근거 중 회수한 비율이다. 두 점수는 문항별로 계산한 뒤 같은 가중치로 평균하였다. 정답 근거는 평가 자료가 지정한 법령이며, 선택한 근거와 문자열이 같은지를 비교하였다. 따라서 정답과 다른 근거가 법률적으로 타당한지까지 판정하는 점수는 아니다.

<a id="tab-ch4-main-results"></a>

**표 2. 전체 226문항의 성능. Δ는 Jev−CE이다.**

| 지표 | CE | Jev | Δ | 차이의 95% CI |
| --- | --- | --- | --- | --- |
| **근거 선택** |  |  |  |  |
| F1 | 58.57 | 61.75 | +3.19 | [+0.75, +5.68] |
| Recall | 57.74 | 60.69 | +2.95 | [+0.39, +5.51] |
| EM | 27.88 | 29.65 | +1.77 | [-1.77, +5.19] |
| 완전 회수율 | 34.07 | 34.96 | +0.88 | [-2.90, +4.53] |
| **답변 품질** |  |  |  |  |
| Token F1 | 46.20 | 47.31 | +1.12 | [+0.02, +2.27] |
| LF-Eval | 67.57 | 70.15 | +2.58 | [+0.37, +4.79] |

주: 점수는 원값의 100배이다. EM·완전 회수율은 백분율이며 차이는 %p, 나머지 차이는 점 단위이다. 차이와 신뢰구간(CI)은 반올림 전 값으로 계산하였다. 출처나 정답 근거를 공유하는 문항을 묶은 151개 그룹의 대응 bootstrap 10,000회로 탐색적 구간을 산출했으며, 다중 비교는 보정하지 않았다.

반면 정답 근거를 모두 확보한 문항은 77개에서 79개로 늘어나는 데 그쳤다. 완전 회수율은 정답 근거를 빠짐없이 선택한 비율이고, EM은 정답 외 근거도 없이 정확히 같은 집합을 선택한 비율이다. 완전 회수율의 차이는 0.88%p였으며 신뢰구간은 [-2.90, +4.53]%p였다. EM의 차이도 1.77%p로 신뢰구간에 0을 포함하였다. 따라서 평균적인 회수 수준은 높아졌지만, 필요한 근거를 모두 갖춘 질문이 뚜렷하게 늘었다고 보기는 어렵다.

재정렬 전 두 조건이 공유한 검색 후보의 평균 정답 근거 Recall은 77.21%였다. 재정렬 후 상위 10개 후보에 남은 정답 근거의 평균 Recall은 CE 69.47%, Jev 74.63%였다. 그러나 후보 목록마다 하나만 선택하는 제약 때문에, 상위 후보에 정답이 있어도 모두 선택할 수 있는 것은 아니다. 이 제약 아래 완전 회수가 가능한 문항은 각각 104개와 120개였으나 실제로는 77개와 79개에 머물렀다. 즉, 상위 후보의 개선이 최종 선택으로 모두 이어지지는 않았다. 최종 성능은 재정렬 모델과 후속 언어 모델 선택을 함께 거친 결과로 해석해야 한다.

공개 코드 CE의 F1은 48.72점이었다. CE와의 9.85점 차이는 후보 목록 참조 오류를 고친 결과로, Jev 교체의 개선폭과 구별된다. 공개 코드는 현재 후보 목록에서 고른 번호를 첫 번째 목록에 적용하는 문제가 있었으며, 수정 조건은 현재 목록을 참조하도록 고쳤다. 이 오류가 원 논문의 실제 실행에도 있었는지는 확인되지 않았다.

## 4.3 질문 조건에 따른 성능 차이

Jev의 근거 F1은 2·3-hop 질문에서 높았고, 1-hop에서는 소폭 낮았다([그림 1](#fig-ch4-hop-f1)). hop은 평가 자료가 부여한 추론 단계 구분이며 실제 정답 근거 개수와는 다르다. 1-hop 57문항은 CE 78.07점, Jev 76.90점이었고, 2-hop 127문항은 53.33점과 57.24점, 3-hop 42문항은 47.91점과 54.83점이었다.

<a id="fig-ch4-hop-f1"></a>

![공식 hop별 최종 근거 F1](figures/hop_f1.png)

**그림 1. 추론 단계별 근거 F1. 집단별 신뢰구간은 산출하지 않았다.**

이는 관측 평균의 차이로, 추론 단계에 따라 교체 효과가 달라지는지는 별도로 검정하지 않았다. 특히 3-hop의 완전 회수는 두 조건 모두 1문항(2.38%)이었다. F1이 높아져도 모든 근거를 확보하는 문제는 남았다.

정답 근거를 검색 자료에서 찾을 수 있는지에 따라서도 차이가 컸다. 고유 정답 근거 386개 중 27개는 자료에서 동일 문자열을 찾을 수 없었다. 모든 근거가 대응된 197문항의 F1은 CE 64.12점, Jev 67.21점이었고, 불일치가 있는 29문항은 20.80점과 24.71점이었다. 후자의 낮은 점수에는 검색 성능뿐 아니라 자료의 제약도 반영된다. 문항별로는 Jev 개선 32개, 동일 177개, CE 우세 17개로, 전체 평균의 개선은 일부 질문의 변화에서 발생하였다. 질문들이 출처나 정답 근거를 공유할 수 있으므로, 이 개수를 서로 독립적인 시행의 성공률로 해석하지 않았다.

## 4.4 자동 답변 품질 및 자원 사용 특성

Jev는 답변의 자동 평가에서도 평균 점수가 높았다(표 2). LF-Eval은 2.58점, Token F1은 1.12점 증가하였다. Token F1은 정답과 생성 답변의 공백 단위 표현 중복을 측정하고, LF-Eval은 정답 답변과 정답 근거를 기준으로 LLM이 답변을 평가한다. LF-Eval은 답변이 정답의 법률적 결론이나 근거를 빠뜨리거나 모순되게 서술했는지도 평가한다. 따라서 두 점수의 증가는 각각 표현의 일치와 정답 기준 평가의 개선을 뜻한다. 두 평가에는 공식 코드와 같은 앞 800자 평가 규칙을 적용하였다.

다만 Token F1의 별도 양측 검정 p값은 약 0.0525였다. 표의 신뢰구간과 이 검정은 산출 방식이 달라 결과가 일치하지 않을 수 있으므로, 모든 자동 지표가 통계적으로 유의하게 개선되었다고 해석하지 않았다. 또한 LF-Eval은 실제 선택 근거가 답변을 지지하는지를 직접 평가하지 않는다. 사람 평가는 수행되지 않아 전문가가 판단한 정확성과 근거 지지 여부는 아직 확인되지 않았다.

답변 생성에 제공한 근거의 평균 길이는 CE 203.67토큰, Jev 215.60토큰으로 늘었다. 질문·지시문·예시를 포함한 전체 입력도 평균 2302.67토큰에서 2314.58토큰으로 늘었고, 출력은 72.16토큰과 73.98토큰이었다. 사용량 토큰은 앞서 Token F1에서 사용한 공백 단위와 구별된다. 근거 길이의 중앙값은 각각 164개와 170.5개였고, 질문별 길이 차이의 중앙값은 0개였다. 평균 길이의 증가가 모든 질문에서 발생한 것은 아니다. 선택 목록의 길이는 문항별로 같았으므로, 이는 근거 수를 줄인 결과가 아니라 선택 내용이 달라진 결과이다.

따라서 이번 비교에서 입력량 절감은 관찰되지 않았다. 저장된 생성 응답을 재사용한 질문은 CE 72개, Jev 122개였다. 이 경우에도 동일 입력에 필요한 토큰량을 집계했으므로 신규 청구량을 뜻하지 않는다. 선택·점수화·평가·재시도까지 포함한 전체 서비스 비용은 산출하지 않았다. 실행 시간에는 저장 응답 재사용과 요청 제한 대기가 포함되어 있어 공정한 응답 지연 비교에도 사용할 수 없다. 또한 근거 길이의 증가가 품질 개선의 원인인지는 이 결과로 판단할 수 없다.

## 4.5 오류 유형 및 관측 사례

Jev는 상위 후보에서 정답 근거가 탈락하는 경우를 줄였지만, 이후 선택되지 않는 근거도 남았다. 질문마다 필요한 고유 정답 근거를 따로 세면 총 443건이다. 검색 자료에서 동일 문자열을 찾을 수 없는 근거 33건과, 자료에는 있으나 검색 후보에 없는 75건은 두 조건에서 같았다. 검색 후보에는 있으나 재정렬 후 상위 10개에서 탈락한 근거는 CE 42건, Jev 13건이었다. 상위 10개에 남았으나 최종 선택되지 않은 근거는 60건과 72건이었고, 최종 선택은 233건과 250건이었다. 이 집계는 같은 근거가 여러 질문에 필요하면 각각 세므로, 전체 고유 근거 386개와 다르다.

개선·악화·지표 불일치 집단에서 근거 F1 차이의 크기가 각 집단의 중앙값에 가장 가까운 사례를 하나씩 골라 선택 근거와 답변의 변화를 살펴보았다([표 3](#tab-ch4-cases)).

<a id="tab-ch4-cases"></a>

**표 3. 관측 사례의 점수 변화 (CE → Jev)**

| 사례 | 근거 F1 | Token F1 | LF-Eval |
| --- | --- | --- | --- |
| A | 50.00 → 100.00 | 69.09 → 86.79 | 65.29 → 99.18 |
| B | 80.00 → 40.00 | 32.79 → 29.09 | 71.79 → 52.67 |
| C | 40.00 → 0.00 | 18.60 → 25.88 | 31.10 → 30.55 |

사례 A는 식품 생산실적과 회수계획의 보고 상대방을 묻는 질문이다. CE는 식품위생법 제42조제2항과 생산실적 관련 시행규칙을 선택하였다. Jev는 제42조제2항을 유지하면서 회수계획 관련 정답 근거인 제45조제1항도 확보하였다. 답변에는 시장·군수·구청장이 포함되었고 두 답변 점수도 높아졌다.

사례 B는 여러 당사자에 대한 복수 청구 절차를 묻는 질문이다. CE는 정답 근거인 민사소송법 제79조제1항과 제253조를 모두 선택하였다. Jev에서는 제79조제1항이 상위 후보에서 탈락하고 제83조제1항이 선택되었다. 답변도 독립당사자참가에서 공동소송참가 관련 내용으로 달라졌으며, 근거와 답변 점수는 모두 낮아졌다.

사례 C는 사면과 복수 범죄의 처리를 묻는 질문이다. 정답 근거 3개 중 하나는 검색 자료에서 동일 문자열을 찾을 수 없었고, 다른 하나는 검색 후보에 없었다. 후보 목록도 2개여서 목록마다 하나를 선택하는 방식으로는 정답 근거 3개를 모두 확보할 수 없었다. CE는 정답 근거 하나를 골랐지만 Jev는 고르지 못했다. 그럼에도 Token F1은 높아져, 정답과 표현이 더 비슷한 답변이 반드시 더 나은 근거 선택을 뜻하지 않음을 보여준다.

이 사례들은 자동 관측 결과이며 법률 전문가의 판정은 완료되지 않았다. 특히 상위 후보에 있는 근거를 선택하지 않은 경우에는 목록당 하나만 고르는 제약도 작용할 수 있다. 정답과 문자열이 다른 근거의 법률적 타당성 역시 별도 검토가 필요하다. 상세 평가와 집계·사례 선정 절차는 [보충자료](chapter4-supplement.md)에 제시하였다.
