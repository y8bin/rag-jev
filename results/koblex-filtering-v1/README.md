# 문턱값 필터링 오프라인 시뮬레이션 — 2026-11-09

상태: **탐색적 오프라인 시뮬레이션. 유료 호출 0건. 답변 재생성 없음.**
코드: `scripts/simulate_koblex_filtering.py`. 원 실험(`results/koblex-reproduction-v1/`)은 읽기만 했다.

## 무엇을 했나

완료된 ParSeR 실험의 점수와 최종 선택을 그대로 두고, "점수가 문턱값 τ 미만인 근거를 버리면 어떻게 되는가"를 계산했다.

- **선택 후 필터링(post)**: LLM이 최종 선택한 근거 중 점수 < τ인 것을 제거한다. 0개도 허용한다. 공식 근거 P/R/F1/EM은 정확하게 다시 계산된다. 답변은 다시 생성하지 않았으므로 Token F1과 LF-Eval은 알 수 없다.
- **선택 전 필터링(pre)**: 상위 10개 후보 중 점수 < τ인 것을 LLM에 보여주지 않는다. 이 경우 LLM의 선택이 달라지므로, 상위 후보에 정답 근거가 몇 개 남는지만 정확하게 계산된다.

## 운영점 결정 규칙

- 151개 의존 그룹 단위로 5-fold 교차검증을 했다(seed 20261109).
- 점수 척도가 서로 달라서 scorer마다 학습 fold의 점수 분위수로 20개 격자를 만들었다(유지율 1.00~0.05).
- 학습 fold의 F1이 필터링 전보다 1.0점 넘게 떨어지지 않는 문턱값 중 근거를 가장 많이 줄이는 값을 골라, 검증 fold에 적용했다.
- **수정 이력**: 처음에는 두 scorer에 같은 0.00~0.95 절대 격자를 썼다. 그런데 CE 점수는 대부분 0.05 미만이라 CE는 사실상 필터링 자체가 불가능했다. 그래서 기존 설계(`final_research_strategy.md` 8절: 척도별 격자, 같은 크기)에 맞게 바꿨다.

## 해석과 한계

- Jev 점수로는 근거를 약 11% 줄여도 F1이 통계적으로 구분되지 않았다. 대신 Precision은 오르고 Recall은 떨어졌다. CE 점수로는 같은 규칙에서 2%밖에 줄이지 못했다. 같은 비율을 줄이면 CE의 F1이 더 많이 떨어진다.
- 선택 전 후보를 절반으로 줄여도 Jev는 정답 근거를 대부분 유지했다(72.7% → 69.3%). CE는 66.1% → 51.5%로 떨어졌다.
- **답변 품질(Token F1, LF-Eval)은 측정하지 않았다.** "품질을 유지하면서 비용을 줄였다"는 주장, 즉 비열등성을 말하려면 필터링된 근거로 답변을 재생성하고 다시 평가해야 한다.
- 시험 문항을 이미 본 뒤의 탐색적 분석이다. 교차검증은 같은 226문항 안에서 문턱값 선택과 평가를 분리했을 뿐, 미노출 시험을 대신하지 않는다.
- 정확 문자열 지표라서, 버려진 정답 외 근거가 법적으로 유용했을 가능성은 판정하지 않았다.
