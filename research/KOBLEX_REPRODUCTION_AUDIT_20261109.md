# 현재 실험의 입력 진단과 작업공간 정리

자동 실험·통계·전수 검증은 완료했고 실제 사람 평가는 대기 중이다. 결론은 [결과 보고서](KOBLEX_REPRODUCTION_RESULTS_20261109.md)를 따른다.

## CE 입력 통제 진단

같은 후보20개·N5의 고정30문항으로 입력을 대조했다.

| 입력 | 근거 F1 ×100 |
|---|---:|
| 배경+질문 JSON / 법령 JSON | 17.94 |
| 원 질문 / 원 법령 문자열 | 33.94 |
| 배경+질문 문자열 / 원 법령 문자열 | 18.09 |
| 원 질문 / 법령 JSON | 33.94 |

질문만 입력하면 배경 포함 문자열 대비17개 개선·11개 동일·2개 악화였다. 이 진단은 현재 실험의 방법 점검 기록이며, 다른 모델이나 데이터에 일반화하지 않는다. 진단 입력·점수는 현재 결과 폴더의 `ce-diagnostic*`, CPU/MPS8쌍 점검은 `ce-numerics*`에 있다.

원 공개 코드의 CE 입력은 원 질문 문자열이다. 새 본실험은 이를 따랐고47,800쌍에서 입력 잘림0개, 최대1,420토큰이었다. 공개 코드의 첫 후보 목록 인덱스 오류도 재현해 오류 보존 CE·수정 CE·Jev 교체를 분리했다. 이는 모두 이번 실험의 세 조건이며 삭제 대상인 이전 실행 기록이 아니다.

## 실행 기록

678개 답변과678개 LF-Eval을 완료했다. 요청량 한도로 생긴 중단은 성공 출력과 미정산 예약액을 보존해 재개했다. 요청 스케줄링 이력은 현재 결과의 amendment 파일에 있다. 모델·프롬프트·평가 기준은 바꾸지 않았다. 같은 평가 대상 답변272쌍에서 LF 점수가 동일함을 확인했다.

## 사용자 요청에 따른 정리

이전 Vector·KBL·데모·연결 점검·튜닝 결과, 관련 캐시·인덱스·설정·설계 문서·뷰어·야간 자동 실행 작업을 삭제했다. 과거 결과를 다른 백업 폴더에 옮겨 숨기지 않았다. Git 이력은 다시 쓰지 않았다.

이번 실험의 공식 원문,226문항 입력,세 조건 원시 결과,API 응답,평가·통계,사람 평가 양식,재현에 필요한 모델·의존성은 유지했다. 실제 실행한 코드와 실행 당시 잠금은 그대로 보존했다. 활성 설정·진입점·공식 소스 경로의 정리는 실행 후 작업으로 별도 기록했으며 사전등록을 새로 만들지 않았다.

누적 예산은 초기화하지 않았다. 이전 호출 상세19,587건은 사용액7.130966722달러의 종류별 이월 잔액으로 집계하고 삭제했다. 현재 호출41,322건과 미정산12건은 보존했고, 총100달러·OpenAI37달러 상한과 예약 포함 잔액이 같음을 확인했다.

`cleanup-manifest.json`은 삭제 범위·경로 이동·현재 어댑터 해시·유지한 과학적 결과 해시·예산 이월을 기록한다. `integrity-audit-current.json`은 삭제 후 남은 파일만으로 입력·선택·모델·출력·평가·블라인드 양식을 다시 검증한다. 정리 전 검증 기록은 이번 실행의 과학적 이력으로만 보존한다.
