# 제4장 논문 형식 개정 내역

2026-11-09. [형식 검토서](ATTENTION_FORMAT_REVIEW.md)의 권고를 [제4장 본문](../chapter4.md)에 반영하였다. 수정 전 본문은 [백업](before-attention-revision/chapter4.md)에 보존하였다.

## 반영 내용

- 4.1에 비교 조건·통제 절차·필수 지표 정의를 압축하였다. 결과 절에서 설명을 다시 시작하는 구성과 가상의 지표 예시는 정리하였다.
- 4.2·4.3·4.4·4.5를 주요 관측으로 시작하고, 표·그림을 근거로 차이와 해석 범위를 설명하도록 재배치하였다.
- 4.4를 자동 답변 품질과 답변 생성 입력 요구량의 두 소절로 나누고, 표 2에 있는 답변 점수의 반복 서술을 줄였다.
- 표 2·3·4의 캡션/주석에 차이의 방향·단위·집계 범위·캐시 포함 여부를 보완하였다.
- 사례 표에 Token F1을 추가하였다. A/B/C의 기존 원자료 값을 사용하여 사례 C의 근거 F1 감소와 Token F1 증가를 표에서 직접 비교할 수 있게 했다.
- 절차 상세·지표 예시·bootstrap 설명·캐시 수·사례 식별자·선정 세칙·사람 평가 준비 기록은 [보충자료](../chapter4-supplement.md)에 보존하고 본문에서 연결하였다.
- KoBLEX·ParSeR의 원문 인용을 연결하고, 보충자료에 LF-Eval을 포함한 원문 서지를 제시하였다. 저자·제목은 기존 수집 원문의 첫 페이지 텍스트와 대조하였다. 원문의 점수나 사람 평가 결과를 이번 실험의 결과로 사용하지 않았다.

다른 장 원고를 수정하거나 존재하지 않는 방법 절 번호를 참조하지 않았다. 본문 자체에서 결과를 이해하는 데 필요한 정의는 남겼으며, 옮긴 상세 설명은 보충자료에서 확인할 수 있다.

## 보존 및 검증

주요 성능 표의 모든 값과 신뢰구간, 자원·단계별 표의 기존 수치를 보존하였다. 사례 표의 세 지표는 `manuscript-facts.json`과 대조하였다. 기존 소수 수치의 본문·보충자료 합산 보존, 다섯 절·다섯 표·기존 그림, 내부 및 보충자료 링크를 확인하였다. 원자료·수치 원장·LaTeX·그림 등 24개 기존 파일의 해시가 변경되지 않았음을 확인하였다.

본문 길이는 11,780자에서 9,072자로 바뀌었다(주석·Markdown 표기 포함). 분량 자체보다 결과·방법·관리 기록의 역할 분리에 초점을 두었다.

평균 개선과 완전 회수의 불확실성, 1-hop 감소, 3-hop 완전 회수 1문항, 매핑 불일치, 탐색적 분석과 다중 비교 무보정, Token F1의 구간·검정 차이, 사람 판단 부재 및 비용·지연 해석 범위를 유지하였다. 새 실험·검정·사람 평가는 수행하지 않았다.

확인 결과는 [검증 기록](attention-revision-validation.json)에 남겼다. 이번 개정은 Markdown 본문과 보충자료 대상이며 LaTeX·PDF는 이전 상태이다. 기존 문체/이해도 검증 기록은 각 당시 버전의 기록으로 유지하였다. `tmp/chapter4_to_markdown.py`를 실행하면 LaTeX에서 다시 생성되어 이번 Markdown 개정이 덮어써질 수 있다.
