# 점수화 단계 지연 벤치마크 — 2026-11-09

상태: **탐색적 scorer-only 지연 측정. 60문항 × 3회 반복, 실패 0건.**
코드: `scripts/benchmark_koblex_latency.py`(측정), `scripts/analyze_koblex_latency.py`(집계). 설정은 `protocol.json`에 있다.

## 측정 방법

- 대상: 미리 고정한 사람 평가 표본 60문항(1/2/3-hop 15/34/11). 결과를 보고 고른 표본이 아니다.
- 측정 구간: 한 문항의 모든 후보(중복 제거, 평균 177쌍)를 점수화하고 풀별 상위 10개를 뽑는 데까지. 예상 조문 생성, BM25, LLM 선택, 답변 생성은 제외했다(두 조건에서 같은 구조).
- 캐시 없음. warmup 3문항 제외. 문항 순서와 방법 순서는 무작위(seed 20261109). 두 방법은 동시에 돌리지 않았다.
- CE: Apple M5 Pro 로컬 MPS, float32, batch 50. Jev: 원격 API(`jev-1.14.0`), 동시 요청 4개.
- 분석 단위: 문항별 3회 평균. 52개 의존 그룹으로 대응 bootstrap 10,000회.

## 결과

| | CE (로컬 MPS) | Jev (원격 API) |
|---|---:|---:|
| 문항당 평균 | 5.01초 | 10.65초 |
| 문항당 중앙값 | 4.82초 | 10.79초 |
| 문항당 p95 | 8.87초 | 16.53초 |
| 후보 1쌍당 평균 | 27.6ms | 60.2ms |
| 반복 간 변동계수 | 16.9% | 3.4% |

- Jev − CE: 문항당 **+5.64초** (95% CI +5.15 ~ +6.17). Jev/CE 기하평균 비율 **2.25배** (2.11 ~ 2.39).
- 재현성: CE는 180회 모두 본실험과 상위 10개가 완전히 같았다. Jev는 1.1%만 완전히 같았고, 평균 91.5%가 겹쳤다. 같은 입력이라도 Jev 점수는 호출마다 조금씩 달라진다.
- Jev 비용: $0.61(측정 반복 기준). 재시도 0건.

## 해석 한계

- 모델 자체의 속도가 아니라 "로컬 GPU의 CE vs 원격 API의 Jev"라는 배포 환경 비교다. CE 장비비와 전력비는 반영하지 않았다.
- 한 세션의 네트워크 조건에서 측정했다. 동시 요청 수를 늘리면 Jev 시간은 달라질 수 있다.
- E2E 지연(LLM 선택·답변 포함)은 측정하지 않았다. 이 차이가 그대로 E2E 차이가 된다고 단정하지 않는다.
