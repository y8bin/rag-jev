# 4. 실험 결과 및 분석

## 4.1 실험 조건 요약

KoBLEX의 한국어 법률 질문 226문항을 대상으로 ParSeR의 재정렬 모델을 Cross-Encoder(CE)에서 Decision Model인 Jev로 교체하여 평가하였다. CE는 `dragonkue/bge-reranker-v2-m3-ko`, Jev는 `jev-1.14.0`이며, 선택·답변 생성·자동 평가에는 `gpt-4o-2024-08-06`을 사용하였다. 두 조건은 예상 법령과 BM25 검색 후보를 공유하고, 예상 법령별 후보 100개를 재정렬한 후 상위 10개 중 LLM이 하나를 선택하였다. 총 478개의 후보 목록이 생성되었으며, 선택 개수는 정답 근거 수로 정하지 않았다. CE 입력 형식(원 질문만 사용)은 시험 문항 30개에서 네 가지 형식을 비교한 탐색적 진단을 거쳐 정하였다.

주 기준선은 공개 코드의 후보 목록 참조 문제를 수정한 CE이다. 공개 코드에는 현재 목록에서 선택한 번호를 첫 번째 목록에 적용하는 문제가 있어, 이를 보존한 CE는 재현 참조로 분리하였다. 세 조건의 답변과 자동 평가는 각각 226개씩 완료되었다. 이하 CE는 수정 조건을 뜻한다. 모든 비교는 기존 시험 결과를 확인한 뒤 수행한 탐색적 분석이다. 품질 차이의 95% 신뢰구간(CI)은 출처나 정답 근거를 공유하는 151개 그룹의 대응 bootstrap 10,000회로 산출하였으며, 다중 비교는 보정하지 않았다. 문항별 점수의 평균(P·R·F1, Token F1, LF-Eval)은 0–100 척도의 점으로, 조건을 충족한 문항의 비율(EM, 완전 회수율 등)은 %와 %p로 표기한다. 지연은 hop별 층화 무작위로 미리 추출한 60문항(1/2/3-hop 15/34/11)에서 별도로 측정하고, 표본에 해당하는 52개 의존 그룹으로 같은 방식의 대응 구간을 산출하였다.

## 4.2 Decision Model 적용에 따른 근거 선택 성능 변화 (RQ1)

Jev의 최종 근거 F1은 61.75점으로 CE의 58.57점보다 3.19점 높았다. Precision은 63.46점에서 66.85점으로, Recall은 57.74점에서 60.69점으로 상승하였다. 근거 평가는 선택 근거와 정답 근거(gold)의 정확한 문자열 집합을 비교하고 문항별 점수를 동일 가중치로 평균한다. 따라서 이 결과는 정답 근거와의 일치 수준을 나타내며, 정답 외 근거의 법률적 타당성을 판정하지는 않는다.

![최종 근거 성능의 대응 차이](figures/section-figures-v1/fig_4_2_evidence_effects_column.png)

**그림 1. 최종 근거 성능의 Jev−CE 차이와 탐색적 95% CI. EM·완전 회수율 차이는 %p, 나머지는 점 단위이다.**

F1과 Recall 차이의 CI는 각각 [+0.75, +5.68]점과 [+0.39, +5.51]점이었다(그림 1). 반면 EM은 27.88%에서 29.65%로, 모든 gold를 포함한 완전 회수율은 34.07%에서 34.96%로 증가하는 데 그쳤다. EM은 선택 집합과 gold 집합의 완전 일치이고, 완전 회수는 정답 외 근거가 있더라도 gold를 빠짐없이 포함한 경우이다. 두 차이의 CI는 0을 포함하였다. 평균적인 근거 회수 수준은 높아졌으나, 필요한 근거를 모두 확보한 문항은 77개에서 79개로 소폭 증가하였다.

문항별 F1은 Jev 우세 32개, 동일 177개, CE 우세 17개였다. 공식 hop별 F1은 1-hop에서 78.07→76.90, 2-hop에서 53.33→57.24, 3-hop에서 47.91→54.83이었다. 이는 집단별 관측 평균이며 효과 차이를 검정한 결과는 아니다. 특히 3-hop 완전 회수는 두 조건 모두 1/42문항이었다. 고유 gold 386개 중 27개는 corpus에서 동일 문자열을 찾을 수 없어 29문항에 영향을 주었다. 완전 매핑 197문항의 F1은 64.12→67.21, 영향 29문항은 20.80→24.71이었다. 전체 분석에서는 이 문항들을 제외하지 않았다.

공개 코드 CE의 F1은 48.72점이었다. 수정 CE와의 9.85점 차이는 후보 목록 참조 수정 효과이며, Jev 교체 효과와 구별된다. 공개 스냅샷의 문제가 원 논문의 실제 실행에도 있었는지는 확인되지 않았다.

## 4.3 Decision Model과 Cross-Encoder의 재정렬 성능·지연시간 비교 (RQ2)

최종 선택 이전의 상위 10개 후보를 비교하여 재정렬 단계의 성능을 살펴보았다. 공통 BM25 후보 합집합의 문항별 평균 gold Recall은 77.21점이었다. 재정렬 후 shortlist 합집합의 Recall은 CE 69.47점, Jev 74.63점으로 Jev가 5.16점 높았다. 모든 gold가 shortlist에 남은 문항도 112개(49.56%)에서 130개(57.52%)로 증가하였다(그림 2). 이 수치는 최종 선택 성능과 구별되는 후보 유지 수준이다.

![재정렬 후 상위 후보의 정답 근거 유지율](figures/section-figures-v1/fig_4_3_shortlist_quality_column.png)

**그림 2. 상위 후보 합집합의 정답 근거 유지 수준(226문항). Recall은 문항별 평균(점), 모든 gold 포함률은 문항 비율(%)이며 같은 0–100 축에 표시하였다. 오차막대는 산출하지 않았다.**

후보 유지 수준의 개선이 최종 완전 회수로 모두 이어지지는 않았다. 각 후보 목록에서 하나만 선택하는 제약을 반영하면, shortlist에서 모든 gold를 동시에 선택할 수 있는 문항은 CE 104개, Jev 120개로 줄어든다. 실제 완전 회수는 각각 77개와 79개였다. 따라서 Jev는 상위 후보에서 정답 근거를 더 많이 유지했지만, 후속 선택과 목록 구조의 제약이 남았다. 이 단계의 비교는 관련성 분류 정확도나 최종 답변 정확도와 구별된다.


지연 측정은 동일한 질문–후보 쌍을 문항 내에서 중복 제거한 후 점수화하고, 목록별 정렬과 상위 10개 구성을 마칠 때까지로 정의하였다. 캐시를 비활성화하고 방법별 워밍업 3문항을 제외한 뒤, 문항·방법 순서를 무작위화하여 각각 3회 반복하였다. CE는 로컬 MPS에서 float32·배치 50으로, Jev는 원격 API에서 동시 요청 4개로 실행하였다. 분석 단위는 문항별 3회 평균이며, 총 360개 본 측정에서 실패와 Jev 재시도는 없었다.

**표 1. 재정렬 단계 지연(60문항, 초). 각 문항의 3회 평균 분포에서 계산하였다.**

| 통계량 | CE | Jev |
| --- | --- | --- |
| 평균 | 5.01 | 10.65 |
| 중앙값 | 4.82 | 10.79 |
| 제95백분위수 | 8.87 | 16.53 |

평균 지연은 CE 5.01초, Jev 10.65초로 Jev가 5.64초 길었다(95% CI [+5.15, +6.17]초). 문항별 Jev/CE 비율의 기하평균은 2.25배(CI [2.11, 2.39])였다. 즉, 재정렬 단계에서 Jev는 후보 유지 수준이 높았지만 지연은 더 길었다. 다만 품질은 전체 226문항의 기존 결과이고 지연은 60문항의 별도 실행이므로, 동일 실행에서 품질·시간을 동시에 검증한 결과는 아니다. 이 비교는 로컬 CE와 원격 Jev라는 배포 조건에 의존하며 모델 고유 속도로 일반화할 수 없다. 또한 예상 법령 생성·BM25·LLM 선택·답변 생성·모델 로드를 제외하므로 전체 응답시간의 차이를 뜻하지 않는다.

반복 실행에서 기존 품질 실험과 모든 목록의 상위 10개가 순서까지 일치한 비율은 CE 100%(180/180회), Jev 1.11%(2/180회)였다. Jev의 순서 무관 후보 겹침은 목록별 교집합 비율을 문항 내 평균한 뒤 전체 실행에서 평균했을 때 91.51%였다. 따라서 기존 Jev 품질 수치는 저장된 실행 결과에 대한 값이며, 재호출 시 동일한 선택·답변 품질을 보장하지 않는다.

## 4.4 최종 답변의 자동 품질과 자원 사용 특성 (RQ3)

Token F1은 CE 46.20점에서 Jev 47.31점으로, LF-Eval은 67.57점에서 70.15점으로 높아졌다. 차이의 CI는 각각 [+0.02, +2.27]점과 [+0.37, +4.79]점이었다. Token F1은 정답과 생성 답변의 공백 단위 표현 중복을 측정하며, LF-Eval은 정답 답변과 gold에 비추어 법률적 결론·누락·모순을 평가한다. 두 평가에는 공식 코드의 앞 800자 처리 규칙을 적용하였다. Token F1의 별도 centered-bootstrap 양측 p값은 약 0.0525로, percentile CI와 검정의 구성 방식이 다르므로 모든 자동 지표가 유의하게 개선되었다고 해석하지 않았다.

선택 문맥은 평균 203.67토큰에서 215.60토큰으로, 전체 API 입력은 2302.67토큰에서 2314.58토큰으로 늘었다. 출력은 72.16토큰과 73.98토큰이었다. 문맥 길이의 중앙값은 164토큰과 170.5토큰이며, 문항별 길이 차이의 중앙값은 0이었다. 선택 목록은 양쪽 모두 478개로 동일하므로, 이 증가는 선택 수의 차이가 아닌 선택 내용 변화에 따른 결과이다. 본 비교에서 입력량 절감은 관찰되지 않았다. 사용량 토큰은 Token F1의 공백 단위와 다르며, 재사용 응답의 기록도 포함하므로 신규 청구액을 뜻하지 않는다.

추가로 저장된 선택 근거에 문턱값을 적용하는 선택 후 필터링을 수행하였다. 151개 의존 그룹의 5-fold 교차검증에서 학습 fold의 근거 F1 하락이 1점 이내인 후보 중 근거를 가장 적게 남기는 문턱값을 고르고 검증 fold에 적용하였다. scorer별 점수 척도를 고려해 동일한 크기의 분위수 격자를 사용하였다. 답변 생성 전에 정한 이 문턱값을 고정한 뒤, 유지 근거가 바뀐 문항(CE 10개, Jev 45개)만 같은 프롬프트와 `gpt-4o-2024-08-06`으로 답변을 재생성하고 같은 절차로 Token F1과 LF-Eval을 평가하였다. 나머지 문항(CE 216개, Jev 181개)은 생성 입력이 같아 기존 답변을 재사용했으며, 재사용 문항의 LF-Eval 점수가 기존 값과 같음을 확인하였다.

**표 2. 선택 후 필터링의 검증 fold 통합 결과와 답변 재평가(226문항). P·R은 근거 Precision·Recall이다.**

| 조건 | 유지 근거 | F1 | P | R | Token F1 | LF-Eval |
| --- | --- | --- | --- | --- | --- | --- |
| CE | 478 | 58.57 | 63.46 | 57.74 | 46.20 | 67.57 |
| CE+필터링 | 467 | 58.54 | 64.56 | 57.15 | 45.65 | 67.13 |
| Jev | 478 | 61.75 | 66.85 | 60.69 | 47.31 | 70.15 |
| Jev+필터링 | 426 | 61.43 | 69.80 | 58.26 | 47.03 | 69.13 |

Jev는 근거의 89.12%를 유지하면서 근거 F1이 0.32점 낮아졌고(CI [−1.76, +1.07]점), Precision은 2.95점 높아졌으나 Recall은 2.43점 낮아졌다(표 2). 근거가 하나도 남지 않은 문항은 CE 1개, Jev 4개였다. 같은 분포에서 근거를 90% 유지한 기술통계에서도 F1은 CE 57.21, Jev 61.66이었다. 선택 전 필터링에서는 shortlist 후보를 약 절반으로 줄일 때 문항별 gold 출현 443건 기준 유지 비율이 CE 66.14→51.47%, Jev 72.69→69.30%였다. 이 비율은 그림 3과 분모가 같고 그림 2의 문항별 평균 Recall과는 다르다.

답변 재평가에서 Jev+필터링의 Token F1은 47.31→47.03점(차이 −0.28, CI [−1.10, +0.44]), LF-Eval은 70.15→69.13점(−1.02, CI [−2.23, +0.15])이었다. CE+필터링의 차이는 Token F1 −0.54점(CI [−1.19, −0.07]), LF-Eval −0.44점(CI [−1.22, +0.14])으로, Token F1 감소의 구간은 0을 포함하지 않았다. Jev+필터링과 CE+필터링의 차이는 Token F1 +1.38점(CI [+0.09, +2.69]), LF-Eval +2.00점(CI [−0.36, +4.32])이었고, 필터링하지 않은 CE와의 차이는 각각 +0.83점(CI [−0.39, +2.00])과 +1.56점(CI [−0.83, +3.86])이었다. 이 탐색적 분석에서 Jev의 두 감소는 0과 구분되지 않았으나 LF-Eval 구간 하한은 −2.23점이었다. 사전에 정한 비열등성 마진이 없으므로 근거 F1과 답변 지표의 결과 모두 품질의 유지나 동등성으로 해석하지 않는다.

필터링은 유지 근거 수를 줄였을 뿐이며, 이에 따른 비용·지연 변화는 측정하지 않았다. 또한 LF-Eval은 실제 제공 근거가 답변의 주장을 지지하는지를 직접 평가하지 않는다. 지연 벤치마크의 Jev 본 측정 요청 비용은 약 0.61달러였으나, CE 장비·전력 및 후속 생성 비용을 포함하지 않아 전체 서비스 비용 비교에는 사용하지 않았다. 본 절의 결과는 자동 답변 품질과 자원 요구량에 한정된다.

## 4.5 오류 유형 및 사례 분석

단계별 실패를 구분하기 위해 한 문항 내 고유 gold를 한 번씩 세고, 같은 gold가 다른 문항에 필요하면 각각 집계하였다. 총 443건의 출현을 최초 탈락 단계 또는 최종 선택 상태에 배정하였다(그림 3). corpus 미매핑 33건과 BM25 미회수 75건은 공통이었다. shortlist 탈락은 CE 42건에서 Jev 13건으로 줄었으나, shortlist에 남은 뒤 미선택된 출현은 60건과 72건이었다. 최종 선택은 233건에서 250건으로 증가하였다. 이 분모는 전역 고유 gold 386개 및 문항별 평균 Recall과 다르다.

![단계별 정답 근거 탈락과 최종 선택](figures/section-figures-v1/fig_4_5_gold_loss_stages_column.png)

**그림 3. 문항별 gold 출현 443건의 배타적 단계 분류. 미선택은 목록별 선택 수 제약의 영향도 받는다.**

개선·CE 우세·지표 불일치 집단에서 F1 차이 절댓값이 각 집단의 중앙값에 가장 가까운 문항을 대표 사례로 선정하였다. 식품 생산실적과 회수계획의 보고 상대방을 묻는 개선 사례에서는 Jev가 식품위생법 제42조제2항을 유지하면서 제45조제1항을 추가로 확보하였다. 근거 F1은 50→100, LF-Eval은 65.29→99.18로 높아졌다. 반면 복수 당사자 청구 절차 사례에서는 정답 근거인 민사소송법 제79조제1항이 Jev의 shortlist에서 탈락하고 제83조제1항이 선택되었다. 답변의 절차 설명도 달라져 F1은 80→40, LF-Eval은 71.79→52.67로 낮아졌다.

사면과 복수 범죄 처리 사례는 gold 3개에 후보 목록이 2개뿐이어서 모든 근거를 선택할 수 없었다. gold 중 하나는 corpus 미매핑, 하나는 BM25 미회수였으며, Jev는 CE가 선택한 나머지 gold도 확보하지 못했다. 근거 F1은 40→0으로 낮아졌지만 Token F1은 18.60→25.88로 상승하였다. 표현 중복의 증가가 더 나은 근거 선택을 보장하지 않음을 보여준다. 이러한 사례는 자동 관측에 근거하며, 정답 외 조문의 법률적 부적절성이나 실제 주장 미지지를 확정한 것은 아니다. 사례 식별자와 선정 규칙, 원문의 위치는 보충자료에 제시하였다.
