# 원 KOBLEX 재현 실험의 사람 평가

현재 판단 입력 전이다. 이 문서는 새 재현 실험 전용이며 기존 Vector 실험 양식과 혼합하지 않는다.

완성된 양식 위치: `results/koblex-reproduction-v1/human-review/reviewer-A.jsonl`, `reviewer-B.jsonl`.
각 평가자는 공식 60문항의 세 조건 답변 180개를 독립적으로 검토한다. 총360개 판단이다. 조건 이름은 가리고 각 평가자의 표시 순서를 다르게 한다. 실제 법률 판단을 자동 모델로 대신 채우지 않는다.

관리자만 `private/condition-key.jsonl`을 보관한다. 각 평가자에게는 자신의 JSONL과 이 안내만 전달한다. 독립 제출 전 상대 평가·방법 이름·자동 점수·지연을 보여주지 않는다. 전달은 연구팀이 직접 수행한다. 이 작업에서 메일·메시지를 발송하지 않았다.

## 기록할 값

- `correctness_0_1_2`: 0=핵심 결론 또는 법률 적용 오류/무응답, 1=일부 정답이나 중요한 요건·예외 누락, 2=핵심 결론과 필요한 요건·예외 충족.
- `selected_evidence_support_0_1_2`: 0=핵심 주장 미지지, 1=중요한 전제·참조 조문 누락, 2=핵심 주장을 제공된 선택 근거로 추적 가능.
- `unsupported_legal_claim`: 제공된 선택 근거로 뒷받침되지 않는 중요한 법률 주장이 하나라도 있으면 true, 없으면 false.
- `notes`: 오류 조문·요건·예외, 공식 정답에 대한 의심, 불확실한 이유.

정확성은 질문·공식 정답·정답 근거로 판단한다. 선택 근거 충실도는 제공된 선택 근거만을 사용한다. 평가자의 지식으로 누락된 근거를 보충하지 않는다. 답변이 없으면 두 서열 점수는0, unsupported_legal_claim은 false로 기록한다.

질문·답변·근거·review_id는 수정하지 않는다. 최초 제출 파일은 보존한다. 연구 관리자는 누락과 값 범위만 확인하며 내용 판단을 유도하지 않는다. 두 사람의 독립 제출을 받은 뒤 원 일치율과 linear-weighted Cohen kappa(서열 항목), Cohen kappa(이진 항목)를 계산한다. 불일치는 법률 전문가 조정자가 별도 파일에서 조정하고 이유를 남긴다. 조정 후 값으로 독립 일치도를 계산하지 않는다.

## 연구팀이 입력할 실제 참여 정보

평가자A/B 및 조정자C의 법률 교육·과정, 실무 경험 범위, 실제 평가일, 이해관계, 소요 시간을 기록한다. 확인되지 않은 자격·참여·일치도를 추정해 논문에 쓰지 않는다.

기존 연구팀 예정 일정은 2026-11-15~21일이다. 실제 참여와 일정은 팀이 확인한다. 사람 평가 전에는 자동 결과만 완료로 표시한다.

## 독립 제출 뒤 검증과 조정

원본 양식을 복사해 판단을 입력한 뒤, 독립 제출본은 별도 파일로 보존한다. 다음 명령은 빈 양식·누락 판단·질문/답변/근거 변경을 거부한다.

```bash
.venv/bin/python scripts/analyze_koblex_human_review.py \
  --first /path/to/filled-A.jsonl \
  --second /path/to/filled-B.jsonl \
  --output results/koblex-reproduction-v1/human-review-analysis-v1
```

`agreement.json`은 최초 독립 판단의 일치율·Cohen kappa와 source/gold 의존 그룹 단위2,000회 bootstrap 구간을 담는다. 모든 값이 같은 경우처럼 kappa가 정의되지 않으면 null로 두고 1로 만들지 않는다. `adjudication-tasks.jsonl`은 불일치 항목과 양쪽 판단·이유를 제시하고 최종 조정 값은 빈칸으로 남긴다. 최초 독립 제출본을 수정하지 않는다. 조정자는 최종 판단과 이유를 실제로 입력해야 한다.

현재 실제 독립 제출본이 없으므로 일치도나 조정 결과를 생성하지 않았다. 도구 테스트의 가상 판단은 연구 결과에 포함하지 않는다.
