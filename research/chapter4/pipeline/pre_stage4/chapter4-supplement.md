# 제4장 보충 자료

이 자료는 [제4장 본문](chapter4.md)의 평가·집계 방식과 사례 선정 상세를 제공한다. 기존 원자료와 평가 절차를 설명하며, 본문에 없는 새로운 실험이나 통계 검정을 추가하지 않는다.

## S1. 평가 절차와 지표 정의

예상 법령은 질문과 배경을 바탕으로 모델이 생성한 검색용 법령 문구이며, 평가 자료가 제공한 정답 근거(gold)와 구별된다. 각 예상 법령을 이용해 corpus에서 BM25 후보 100개를 검색하고, 원 질문과 후보 법령을 CE(`dragonkue/bge-reranker-v2-m3-ko`) 또는 Jev로 점수화하여 상위 10개 shortlist를 구성하였다. LLM은 목록마다 하나를 선택하고, 선택 근거를 답변 생성 모델에 제공하였다. 서로 다른 목록에서 같은 근거를 선택할 수 있으므로 선택 항목 수와 고유 근거 수는 다를 수 있다.

근거 평가는 문항별로 최종 선택 근거와 gold의 문자열 집합을 비교한다. 중복 문자열은 한 번만 센다. 정밀도는 선택 근거 중 gold의 비율, Recall은 gold 중 선택된 비율이며 F1은 두 값의 조화평균이다. EM은 두 집합의 완전 일치 여부이고, 모든 gold 포함 여부는 gold가 선택 집합에 모두 포함되는지를 나타낸다. F1·Recall은 문항별 점수의 비가중 평균으로 0–100 척도의 점으로, EM·모든 gold 포함률은 해당 조건을 충족한 문항의 비율로 %와 %p로 표기한다. CE 입력 형식은 기존 시험 문항 30개에서 네 가지 입력 형식(배경 포함 여부, 법령 표기 방식)을 비교한 탐색적 진단(`results/koblex-reproduction-v1/ce-diagnostic-summary.json`) 후 원 질문만 사용하는 형식으로 정하였다. 이 진단은 미노출 시험이 아니다.

예를 들어 gold가 A·B인 문항에서 A만 선택하면 부분 회수이다. A·B·C를 선택하면 완전 회수이지만 EM은 충족하지 않는다. A·B만 선택해야 완전 회수와 EM을 모두 충족한다.

Token F1은 정규화한 생성 답변과 정답 답변을 공백 단위로 나누어 토큰 중복을 측정한다. 사용량 토크나이저의 토큰과는 다른 단위이다. LF-Eval은 LLM 평가기가 공식 정답 답변과 gold를 기준으로 답변의 법률적 정확성, 누락, 모순 등을 평가한다. 실제 시스템이 제공한 근거를 기준으로 한 주장 지지 평가와는 구별된다. 두 자동 평가 모두 공식 코드의 처리 규칙에 따라 생성 답변을 전처리하고 앞 800자까지 사용하였다.

신뢰구간은 같은 출처나 gold를 공유하는 문항을 묶은 151개 의존 그룹에 대해 산출하였다. 각 문항의 두 조건 결과를 짝지은 채 그룹 단위로 복원추출하는 대응 bootstrap을 10,000회 수행하고, 차이 분포의 양끝 2.5%를 제외한 percentile 구간을 사용하였다. 문항별 점수는 동일 가중치로 집계하며, 다중 비교는 보정하지 않았다. Token F1에 보고한 centered-bootstrap 양측 p값은 이 percentile 구간과 같은 방식으로 구성한 구간·검정 쌍이 아니다.

## S2. 공개 코드의 후보 목록 참조 문제

공개 코드는 여러 후보 목록에 대한 LLM 선택 결과를 처리할 때 현재 목록 대신 항상 첫 번째 목록의 같은 번호를 참조한다. CE와 Jev 조건은 현재 목록에서 선택된 번호를 읽도록 수정하였다. 공개 코드 CE는 원래 동작을 보존한 참조이며, CE는 후보 목록 참조 방식을 수정한 주 기준선이다. 따라서 공개 코드 CE와 CE의 차이는 이 문제의 수정에 따른 변화이고, CE와 Jev의 차이가 모델 교체의 주 비교이다.

확인 대상은 공개 코드 스냅샷이며, 원 논문의 실제 실행에도 같은 문제가 있었다고 판정한 것은 아니다.

## S3. 자원 사용량과 캐시의 집계

문맥 토큰은 실제 선택 목록의 순서와 중복을 유지하고 줄바꿈으로 연결한 문자열에 `o200k_base` 토크나이저를 적용해 산출하였다. 전체 API 입력·출력량은 생성 응답의 사용량 기록에서 가져왔다. 전체 입력에는 선택 근거 외에 질문·지시문·예시가 포함된다. IQR은 제3사분위수와 제1사분위수의 차이로, 가운데 절반의 값이 퍼진 폭을 나타낸다.

저장된 생성 응답을 재사용한 문항은 CE 72개, Jev 122개였다. 이 문항도 동일 입력과 답변에 해당하는 토큰량을 포함하여 집계하였다. 본문의 사용량은 조건별 생성 단계 요구량이며 이번 실행의 신규 청구액이 아니다. 근거 선택·점수화·평가·재시도와 로컬 CE 운영비를 포함한 독립 서비스 비용은 산출하지 않았다. 실행 시간에는 캐시와 요청 제한 대기가 포함되어 응답 지연의 공정한 비교에 사용할 수 없다.

## S4. 관측 유형과 사례 선정

단계별 집계에서는 한 문항 안의 고유 gold를 한 번씩 세고, 같은 gold가 다른 문항에도 필요하면 각 문항에서 따로 센다. 이 방식의 출현은 조건별 443건이며, 전체 문항에서 중복을 제거한 고유 gold 386개와 구별된다. 각 출현은 최초 탈락 단계 또는 최종 선택 상태 하나에만 배정하였다. 반면 한 문항에는 여러 관측 유형이 겹칠 수 있으므로, 문항별 관측 유형 빈도의 합이 전체 오류 문항 수를 뜻하지는 않는다.

사례 A는 근거 F1이 Jev에서 개선된 집단, B는 CE가 높은 집단, C는 근거 F1과 답변 Token F1 또는 LF-Eval이 엄격히 반대 방향으로 변한 집단에서 선정하였다. 각 집단의 근거 F1 차이 절댓값 중앙값에 가장 가까운 문항을 택하였으며, 동률이면 query_id의 사전순으로 정하였다. 선정된 C는 근거 F1과 Token F1의 불일치 사례이다.

| 사례 | 문항 식별자 | 관측 유형 |
| --- | --- | --- |
| A | `qa_124_2hop_480_rand` | Jev 개선 |
| B | `qa_324_2hop_515` | CE 우세 |
| C | `qa_443_3hop_703` | 근거 F1 감소·Token F1 증가 |

세 사례의 배경·질문, gold 조문, 조건별 선택 조문과 생성 답변 원문은 `results/koblex-reproduction-v1/chapter4-prep-v1/A6/casebook.jsonl`의 해당 `query_id` 행(`background`, `question`, `gold_provisions`, `reference_answer`, `conditions`)에 있다. 자동 평가기의 설명은 법률 판정으로 사용하지 않았으며, 사례 분석은 자동 관측에 근거하고 정답 외 조문의 법률적 적절성은 판정하지 않았다.

본문 수치와 사례별 평가값의 출처는 `results/koblex-reproduction-v1/analysis.json`, `results/koblex-reproduction-v1/chapter4-prep-v1/`(A1~A6), `results/koblex-latency-v1/summary.json`, `results/koblex-filtering-v1/summary.json`과 `e2e-summary.json`이다.

## S7. 선택 후 필터링과 답변 재생성

본문 표 2의 근거 지표는 `results/koblex-filtering-v1/summary.json`의 `cv_overall`과 대응 bootstrap에 근거한다. 의존 그룹 151개를 5-fold로 나누었으며 seed는 20261109이다. 각 scorer의 학습 fold 점수 분위수로 유지율 1.00~0.05의 20개 격자를 구성했다. 학습 fold의 F1이 원래 값보다 1점 넘게 낮아지지 않는 후보 중 유지 근거 수가 가장 적은 문턱값을 선택하여 검증 fold에 적용했다. 학습 fold의 허용 하락폭은 검증 fold의 성능 보장이나 비열등성 한계 검정이 아니다.

CE의 fold별 문턱값은 0 또는 약 0.0000037~0.0000038, Jev는 0.30~0.40이었다. 검증 fold 통합 유지율은 CE 467/478=97.70%, Jev 426/478=89.12%였다. 이미 본 시험 문항 안의 탐색적 교차검증이므로 미노출 외부 시험을 대신하지 않는다. bootstrap 구간 역시 비열등성 입증으로 사용하지 않는다.

`post_matched_keep_rate.csv`는 전체 분포에서 동일 비율의 선택 근거를 유지한 기술통계다. `pre_matched_keep_rate.csv`는 선택 전 shortlist 후보를 제거했을 때 문항별 gold 출현 443건 기준의 유지 비율(예: CE 293/443=66.14%, Jev 322/443=72.69%에서 시작)을 계산한다. 이 분모는 문항별 평균 Recall의 분모와 다르며, 선택 전 필터링에서는 LLM 선택을 다시 실행하지 않았으므로 최종 선택·답변 결과를 뜻하지 않는다.

선택 후 필터링의 답변 재평가(표 2의 Token F1·LF-Eval)는 `results/koblex-filtering-v1/e2e-summary.json`과 `e2e/`의 예측·LF-Eval 결과(조건별 226행)에 근거한다. 위 교차검증 문턱값은 근거 F1만으로 답변 생성 전에 정했고 이후 바꾸지 않았다. 유지 근거가 원 선택과 달라진 문항(CE 10개, Jev 45개)만 주 실험과 같은 답변 프롬프트와 `gpt-4o-2024-08-06`으로 재생성했으며, 근거가 모두 제거된 문항은 빈 문맥으로 생성했다. 나머지 문항(CE 216개, Jev 181개)은 생성 입력이 같으므로 원 답변을 재사용했고, 재사용 문항의 LF-Eval 점수가 원 실험과 같음을 확인했다. 차이의 구간은 같은 151개 그룹의 대응 bootstrap 10,000회(seed 20261108)로 산출했다. 비열등성 마진을 사전에 정하지 않았으므로 이 구간은 품질 유지나 동등성의 근거로 사용하지 않는다. 필터링에 따른 실제 비용·지연 변화는 측정하지 않았다.

## S8. 본문 그림과 편집 범위

본문은 완료된 근거 선택·재정렬 품질·자동 답변·자원 집계·지연 벤치마크(60문항)·선택 후 필터링과 그 답변 재평가·사례 분석을 수록한다. 그림 1~3은 각각 `fig_4_2_evidence_effects_column`, `fig_4_3_shortlist_quality_column`, `fig_4_5_gold_loss_stages_column`이며 기존 원자료를 85mm 단 너비에서 읽을 수 있도록 다시 조판했다. 수치를 새로 추론하거나 신뢰구간을 추가 계산하지 않았다.

조건 흐름도와 자동 답변·토큰 비교 그림을 포함한 절별 전체 figure는 [그림 자료집](figures/section-figures-v1/README.md)에 보존하였다. 본문의 표·수치와 중복되는 그림은 본문에서 생략했다. 지면은 `preview.tex`의 A4, 10pt, 2단, 여백 20mm 기준으로 검증하며 학회 최종 양식의 페이지 수까지 보장하는 것은 아니다.


## S9. 완료된 재정렬 지연 벤치마크

출처는 `results/koblex-latency-v1/protocol.json`, `raw.jsonl`, `summary.json`, `completed.json`이다. hop별 층화 무작위 추출(seed 20261108)로 사전에 고정한 60문항 표본(1/2/3-hop 15/34/11)을 사용했으며, 이는 연구 전체의 사전확증 실험이나 사전등록을 뜻하지 않는다. 캐시를 사용하지 않고, 각 방법의 워밍업 3문항을 제외한 360개 본 측정을 집계했다. 문항과 방법 순서는 seed 20261109로 무작위화했으며 두 방법을 동시에 실행하지 않았다. 질문–후보 쌍은 문항 내 법령 문자열 중복을 제거하여 두 방법에서 같게 구성했다. 문항별 후보 쌍은 평균 176.98개였다.

각 문항의 방법별 세 번 지연을 평균하여 문항당 하나의 관측값을 만들었다. 표 1의 중앙값 및 제95백분위수는 이 60개 평균값의 분포에서 계산한 것으로, 모든 개별 요청의 응답시간 분포가 아니다. Jev−CE 차이는 원래 source/gold 그룹 중 이 표본에 해당하는 52개 그룹의 대응 percentile bootstrap 10,000회(seed 20261108)로 평가했다. Jev/CE 기하평균 비율의 구간은 문항별 시간 비율의 로그에서 같은 bootstrap을 수행한 뒤 지수 변환했다. 이는 평균 시간의 단순 비율과 구별된다.

CE는 로컬 MPS, float32, batch 50이고 Jev는 원격 API, concurrency 4였다. 측정은 고유 후보 점수화와 pool별 정렬/top-10 구성을 포함한다. 예상 법령 생성, BM25, LLM 선택, 답변 생성, 모델 로드는 제외했다. 따라서 한 네트워크 세션의 배포 환경 비교이며, 모델 고유 속도 또는 전체 서비스 응답시간으로 확장하지 않는다.

기존 품질 실행 대비 완전 일치는 각 문항의 모든 pool에 대해 top-10 row ID 목록과 순서가 동일한지 비교했다. CE는 180/180회, Jev는 2/180회였다. 집합 겹침은 각 pool의 두 top-10 row ID 집합 교집합 크기를 10으로 나누고, pool들을 문항 내 평균한 후 180회에서 평균한 값이다. Jev의 평균은 0.9150925926이다. 이 결과만으로 변화가 동률 순서 변경인지 모든 관련도 값의 변화인지 단정하지 않으며, 후속 답변을 재생성·재평가한 것으로 취급하지 않는다.

문항별 반복 지연 변동계수의 평균은 CE 16.93%, Jev 3.43%였다. 이는 후보 재현성과 다른 개념이다. Jev 본 측정의 API 비용은 0.6100542달러이며 워밍업·기타 단계·로컬 CE 장비 및 전력 비용을 포함한 총비용 비교가 아니다. 실제 실패와 재시도는 0건이다.
