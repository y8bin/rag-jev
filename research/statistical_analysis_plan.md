# 통계 분석 계획 — 확정 전 초안

상태: **DRAFT**. 범위·실제 독립 그룹 수·파일럿 불일치율·검정력·margin 근거가 채워지기 전 본 시험을 시작하지 않는다. 이 문서는 구현의 기본 분석과 남은 연구 결정을 구별한다.

## 추정 대상과 주 비교

기본 추정 대상은 평가 대상 질문의 질문 가중 평균이다. 그룹을 같은 가중치로 평균하지 않는다. 품질 주 분석은 모든 실행 조건이 기술적으로 성공한 공통 질문의 `complete_case=true`다. 같은 공통 성공 집합에서 아래 세 비교를 한 주 가족으로 보고한다. 계획 전체 태스크 성공률과 `complete_case=false` 결과는 실패 영향의 보조 분석이다. 비용 usage 누락이 하나라도 있는 비교에는 비용 추론을 제공하지 않는다.

| 가족 | 비교(treatment − baseline) | 지표 |
|---|---|---|
| 주 1 | Jev-R − CE-R | ESR |
| 주 2 | Jev-R − CE-R | grounded_correct v2 |
| 주 3 | Jev-FR − CE-FR | 총 온라인 USD/질문 |
| 보조 | CE-FR − CE-R, Jev-FR − Jev-R | ESR·grounded_correct·온라인 USD |
| 보조 | Jev-FR − CE-FR | ESR·grounded_correct |

Vector, strict_grounded_correct, answerability·질문 유형·문서 유형, ablation, calibration은 보조/탐색 결과다. 시험을 보고 주 지표나 가족을 바꾸지 않는다. 조건이 개발에서 불가능하면 해당 비교는 `condition_not_run`으로 보고한다.

## 분모·실패·누락

| 결과 | 분모/처리 |
|---|---|
| 태스크 성공률 | 계획된 모든 질문×조건, API/파싱 실패는 실패 |
| ESR·Recall | answerable만. 충분 집합 단위. 근거 부족 질문 제외 |
| nDCG/MRR/Precision | 후보 등급 완결성 및 선택 조건 충족 시. 후보 풀 IDCG, FR도 공통 N |
| grounded_correct | 사전에 고정한 사람 평가 표본 중 answerable. 성공 답변의 v2 필수 판정 누락 시 집계·추론 보류 |
| planned 답변 결과 | answerable 기술 실패·보류는 0. 미검토 성공 답변은 미확인 |
| 총비용 | usage·단가·재시도 청구가 모두 확인된 경우. 누락이 있으면 조건 평균과 paired 비용 추론 보류 |
| 지연 | fresh benchmark 성공 지연의 평균·중앙·p95와 실패 지연·실패율 별도 |

유형/answerability 순환 표본은 모집단 비율을 바꿀 수 있다. 현 구현은 표본 질문의 비가중 평균이며 원분포로 자동 가중하지 않는다. manifest의 population/selected strata·선택 그룹 수를 보고한다. 전체 분포를 추정하려면 시험 전에 별도 표본 확률·가중 집계 계획과 구현을 확정한다.

## CI와 다중 비교

질문별 paired 차이를 연결 문서 계열 단위로 bootstrap한다. 같은 그룹 질문을 함께 뽑고 질문 가중 평균을 계산한다. 기본 반복 2,000, seed 20261009, 양측 percentile 95% CI, 그룹 단위 sign-flip p-value를 사용한다. 실제 규모에서 Monte Carlo 정밀도와 그룹 수를 검토한 뒤 반복 수를 시험 전에 고정한다. 독립 그룹이 2개 미만이면 추론하지 않으며, 2개 이상이라는 사실만으로 충분한 검정력을 보장하지 않는다.

세 주 비교에 Holm 조정을 적용한다. 미실행/미확인 비교가 있어도 원래 가족 수를 보존한다. 보조 가족과 planned 전체/공통 성공 민감도 가족은 따로 조정한다. 민감도 결과를 추가 주 결론으로 쓰지 않는다.

## FR 개발 선택과 시험 비열등성

개발에서는 CE-R 공통 기준선의 ESR·grounded_correct 점추정 제약을 모두 만족하는 threshold 중 최소 총비용을 고른다. 동률은 높은 ESR, 낮은 threshold 순서다. `esr_quality_delta`·`answer_quality_delta`가 지정되면 각 margin을 쓰고, null이면 `quality_delta`를 쓴다. 초기 0.02는 정당화되지 않은 계획값이다.

시험에서는 각 FR − CE-R의 공통 성공 품질 차이에 단측 bootstrap 하한을 계산한다. 하한이 `-margin`보다 커야 해당 제약을 충족한다. 한 FR의 두 품질 제약을 **둘 다** 통과해야 그 방법에 대한 공동 품질 조건을 충족한다(IUT). 두 FR에 대해 각각 유지 주장을 하려면 두 방법 간 다중 비교를 반영한다. `configs/dev.yaml`의 계획값 `noninferiority_alpha=0.025`는 두 FR 공동 주장에 대한 Bonferroni 선택이며 단측 97.5% 하한을 사용한다. 범위와 연구 책임자의 승인일은 아래 미결정 사항에 기록한다. 일반 설정 기본값 0.05를 두 방법의 확증적 유지 주장에 그대로 사용하지 않는다.

유의차 없음으로 품질 유지를 주장하지 않는다. 개발 제약을 충족하지 못한 FR은 불가능 결과를 보고하며, 사전 지정한 `--allow-infeasible` 분기에서는 해당 FR만 제외하고 고정 N 및 가능한 FR을 계속 실행한다. margin을 완화하지 않는다.

## 파일럿으로 확보할 통계 입력

- baseline ESR·v2 답변 비율, paired 불일치의 방향·빈도, 최소 탐지 효과와 허용 margin 근거.
- 연결 성분의 수·최대 크기·분포, 질문 유형별 독립 그룹, 그룹 내 상관의 추정/민감도 범위.
- alpha·목표 power·허용 CI 폭·실패율·사람 표본의 제약으로 시험 문항과 그룹 수 산정.
- 두 평가자 불일치·조정 비율, 후보/답변/주장/인용 처리시간, 예상 예산.

현재 파일럿 자료가 없으므로 power·필요 n·baseline을 채우거나 600문항이면 충분하다고 판단하지 않았다. 소수 그룹에서 bootstrap/sign-flip의 한계와 여러 가정의 민감도를 검토한다.
